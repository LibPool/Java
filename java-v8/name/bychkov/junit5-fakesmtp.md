# junit5-fakesmtp

> 标签: Java, Java 8+

## 简介

FakeSMTP for unit-testing smtp clients with JUnit 5

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://bvfalcon.github.io/junit5-fakesmtp/

- 1.0.0
- 1.0.1

- Maven 仓库地址：https://repo.maven.apache.org/maven2/name/bychkov/junit5-fakesmtp/
