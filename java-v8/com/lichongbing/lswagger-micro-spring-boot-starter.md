# lswagger-micro-spring-boot-starter

> 标签: Java, Java 8+

## 简介

Spring Cloud微服务架构下,子服务无需引用前端UI模块,只需引入后端的Jar包

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
