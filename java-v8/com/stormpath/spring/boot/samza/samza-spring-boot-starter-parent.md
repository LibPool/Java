# samza-spring-boot-starter-parent

> 标签: github, Java 8+

## 简介

Starter for running Samza inside a Spring Boot application.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/stormpath/spring/boot/samza/samza-spring-boot-starter-parent/
