# quick-spring

> 标签: Java, Java 8+

## 简介

在main方法中快速使用spring语法的小工具。

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://maven.apache.org

## 历史版本号

- 1.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/ouyanglol/quick-spring/
- Maven 坐标：`com.ouyanglol:quick-spring`
- pom.xml 引用：`<dependency><groupId>com.ouyanglol</groupId><artifactId>quick-spring</artifactId><version>1.0</version></dependency>`
