# tosan-camunda-client-spring-boot-root

> 标签: github, Java 8+

## 简介

This project provides a complete external task Spring-Boot Starter that contains extra features over camunda external tasks starter and also provides a camunda rest client.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
