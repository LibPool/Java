# jackson-datatype-jsr310

> 标签: JSON, 日期时间, Java 8+

## 简介

Add-on module to support JSR-310 (Java 8 Date &amp; Time API) data types.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
