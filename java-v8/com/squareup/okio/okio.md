# okio

> 标签: IO, github, 工具库, Java 8+

## 简介

A modern I/O library for Android, Java, and Kotlin Multiplatform.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
