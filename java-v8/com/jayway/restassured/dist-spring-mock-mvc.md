# dist-spring-mock-mvc

> 标签: Java, Java 8+

## 简介

Spring Mock MVC distribution jar

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/com.jayway.restassured%3Adist-spring-mock-mvc

## 历史版本号

- 2.2.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/jayway/restassured/dist-spring-mock-mvc/
- Maven 坐标：`com.jayway.restassured:dist-spring-mock-mvc`
- pom.xml 引用：`<dependency><groupId>com.jayway.restassured</groupId><artifactId>dist-spring-mock-mvc</artifactId><version>2.2.0</version></dependency>`
