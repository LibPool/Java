# spring-base

> 标签: Java, Java 8+

## 简介

Base package for ApiOmat Microservices based on the Spring framework

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/apiomat/spring-base/
- Maven 坐标：`com.apiomat:spring-base`
- pom.xml 引用：`<dependency><groupId>com.apiomat</groupId><artifactId>spring-base</artifactId><version>1.2.5</version></dependency>`
