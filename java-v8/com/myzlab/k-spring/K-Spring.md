# K-Spring

> 标签: github, Java 8+

## 简介

Library for automatic generation of sql statements for Spring Boot + Hibernate

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/myzlab/k-spring

## 历史版本号

- 1.1.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/myzlab/k-spring/K-Spring/
- Maven 坐标：`com.myzlab.k-spring:K-Spring`
- pom.xml 引用：`<dependency><groupId>com.myzlab.k-spring</groupId><artifactId>K-Spring</artifactId><version>1.1.0</version></dependency>`
- 源码仓库：https://github.com/myzlab/k-spring
