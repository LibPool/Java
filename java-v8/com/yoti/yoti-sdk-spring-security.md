# yoti-sdk-spring-security

> 标签: github, Java 8+

## 简介

Library to integrate the Java Yoti SDK with Spring Security

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/getyoti/yoti-java-sdk

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/yoti/yoti-sdk-spring-security/
- Maven 坐标：`com.yoti:yoti-sdk-spring-security`
- pom.xml 引用：`<dependency><groupId>com.yoti</groupId><artifactId>yoti-sdk-spring-security</artifactId><version>4.4.0</version></dependency>`
