# spring-boot-swagger

> 标签: github, Java 8+

## 简介

Dead simple Swagger config for Spring Boot.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/pjagielski/spring-boot-swagger

## 历史版本号

- 0.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/github/pjagielski/spring-boot-swagger/spring-boot-swagger/
- Maven 坐标：`com.github.pjagielski.spring-boot-swagger:spring-boot-swagger`
- pom.xml 引用：`<dependency><groupId>com.github.pjagielski.spring-boot-swagger</groupId><artifactId>spring-boot-swagger</artifactId><version>0.1</version></dependency>`
