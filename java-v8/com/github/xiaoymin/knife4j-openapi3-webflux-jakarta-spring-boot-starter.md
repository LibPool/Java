# knife4j-openapi3-webflux-jakarta-spring-boot-starter

> 标签: Java, Java 8+

## 简介

SpringWebflux with Knife4j,Only Support OpenAPI3

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/github/xiaoymin/knife4j-openapi3-webflux-jakarta-spring-boot-starter/
