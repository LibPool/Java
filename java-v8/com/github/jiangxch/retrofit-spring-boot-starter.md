# retrofit-spring-boot-starter

> 标签: Java, Java 8+

## 简介

retrofit spring boot starter dependent module

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/com.github.jiangxch%3Aretrofit-spring-boot-starter

## 历史版本号

- 1.0.0-RELEASE

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/github/jiangxch/retrofit-spring-boot-starter/
