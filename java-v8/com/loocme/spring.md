# spring

## 简介

spring - Java library from Maven Central

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/com.loocme%3Aspring

## 历史版本号

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/loocme/spring/
- Maven 坐标：`com.loocme:spring`
- pom.xml 引用：`<dependency><groupId>com.loocme</groupId><artifactId>spring</artifactId><version>7.0.0</version></dependency>`
