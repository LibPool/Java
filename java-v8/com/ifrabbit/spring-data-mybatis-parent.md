# spring-data-mybatis-parent

> 标签: github, Java 8+

## 简介

Spring Data module for MyBatis repositories.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/hatunet/spring-data-mybatis

## 历史版本号

- 2.0.0.RELEASE
- 2.0.1.RELEASE

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/ifrabbit/spring-data-mybatis-parent/
- Maven 坐标：`com.ifrabbit:spring-data-mybatis-parent`
- pom.xml 引用：`<dependency><groupId>com.ifrabbit</groupId><artifactId>spring-data-mybatis-parent</artifactId><version>2.0.1.RELEASE</version></dependency>`
- 源码仓库：https://github.com/hatunet/spring-data-mybatis
