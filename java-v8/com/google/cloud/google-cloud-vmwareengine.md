# google-cloud-vmwareengine

> 标签: github, Java 8+

## 简介

Google Cloud VMware Engine Easily lift and shift your VMware-based applications to Google Cloud without changes to your apps, tools, or processes.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
