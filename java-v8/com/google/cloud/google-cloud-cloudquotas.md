# google-cloud-cloudquotas

> 标签: github, Java 8+

## 简介

Cloud Quotas API Cloud Quotas API provides GCP service consumers with management and observability for resource usage, quotas, and restrictions of the services they consume.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
