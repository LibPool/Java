# google-cloud-firestore

> 标签: github, Java 8+

## 简介

Java idiomatic client for Google Cloud Firestore.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- https://github.com/googleapis/google-cloud-java

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/google/cloud/google-cloud-firestore/
- Maven 坐标：`com.google.cloud:google-cloud-firestore`
- pom.xml 引用：`<dependency><groupId>com.google.cloud</groupId><artifactId>google-cloud-firestore</artifactId><version>3.49.0</version></dependency>`
