# di-spring

> 标签: github, Java 8+

## 简介

Spring annotations support.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/tahonaPL/di-spring

## 历史版本号

- 1.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/pl/tahona/di-spring/
- Maven 坐标：`pl.tahona:di-spring`
- pom.xml 引用：`<dependency><groupId>pl.tahona</groupId><artifactId>di-spring</artifactId><version>1.0.0</version></dependency>`
- 源码仓库：http://github.com/tahonaPL/di-spring/tree/master
