# cdi-api

> 标签: Java, Java 8+

## 简介

APIs for CDI (Contexts and Dependency Injection for Java)

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://cdi-spec.org

## 历史版本号

- 3.0.0-M3

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/jakarta/enterprise/cdi-api/
- Maven 坐标：`jakarta.enterprise:cdi-api`
- pom.xml 引用：`<dependency><groupId>jakarta.enterprise</groupId><artifactId>cdi-api</artifactId><version>3.0.0-M3</version></dependency>`
