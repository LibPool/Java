# uuid-validation-jakarta

> 标签: Java, Java 8+

## 简介

A library for easier validation of UUIDs - jakarta.validation library

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
