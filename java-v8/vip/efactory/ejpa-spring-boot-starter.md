# ejpa-spring-boot-starter

> 标签: github, Java 8+

## 简介

基于jpa再封装,常用的模板CRUD,分页排序,多字段高级搜索、国际化，属性校验,多租户等功能,详见：https://github.com/vip-efactory/ejpa-example.git

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
