# junit

> 标签: 单元测试, 测试, Java 8+

## 简介

JUnit is a unit testing framework for Java, created by Erich Gamma and Kent Beck.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/junit/junit/
- Maven 坐标：`junit:junit`
- pom.xml 引用：`<dependency><groupId>junit</groupId><artifactId>junit</artifactId><version>4.13.2</version></dependency>`
- 源码仓库：https://github.com/junit-team/junit4
