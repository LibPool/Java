# spring-beans

> 标签: github, Java 8+

## 简介

An additional Spring XML Namespace providing various bean creation utilities

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://stuartgunter.github.com/spring-beans

## 历史版本号

- 1.0.0
- 1.0.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/stuartgunter/spring-beans/
- Maven 坐标：`org.stuartgunter:spring-beans`
- pom.xml 引用：`<dependency><groupId>org.stuartgunter</groupId><artifactId>spring-beans</artifactId><version>1.0.1</version></dependency>`
- 源码仓库：https://github.com/stuartgunter/spring-beans
