# freemarker

> 标签: 模板引擎, Java 8+

## 简介

FreeMarker is a "template engine"; a generic tool to generate text output based on templates.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
