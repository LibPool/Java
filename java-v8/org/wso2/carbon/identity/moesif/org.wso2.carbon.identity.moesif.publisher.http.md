# org.wso2.carbon.identity.moesif.publisher.http

> 标签: Java, Java 8+

## 简介

Custom HTTP output event adapter that formats and forwards identity events to the Moesif APIs, including Moesif-specific body construction, User-Agent header injection, API key authentication and per-event URL suffix routing (actions / users / companies).

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
