# mapstruct

> 标签: 代码生成, 对象映射, Java 8+

## 简介

An annotation processor for generating type-safe bean mappers

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
