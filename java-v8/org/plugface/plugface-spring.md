# plugface-spring

> 标签: Java, Java 8+

## 简介

Spring Framework integration for PlugFace, manage plugins as Spring Beans

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.plugface%3Aplugface-spring

## 历史版本号

- 0.6.0
- 0.6.1
- 0.7.0
- 0.7.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/plugface/plugface-spring/
- Maven 坐标：`org.plugface:plugface-spring`
- pom.xml 引用：`<dependency><groupId>org.plugface</groupId><artifactId>plugface-spring</artifactId><version>0.7.1</version></dependency>`
