# wildfly-transaction-client-jakarta

> 标签: Java, Java 8+

## 简介

Client library for applications using transactions with Wildfly Jakarta edition

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
