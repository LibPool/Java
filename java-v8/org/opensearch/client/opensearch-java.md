# opensearch-java

> 标签: github, Java 8+

## 简介

High level OpenSearch Java Client.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/opensearch/client/opensearch-java/
- Maven 坐标：`org.opensearch.client:opensearch-java`
- pom.xml 引用：`<dependency><groupId>org.opensearch.client</groupId><artifactId>opensearch-java</artifactId><version>3.10.0</version></dependency>`
