# opensearch-custom-codecs

> 标签: github, Java 8+

## 简介

OpenSearch plugin that implements custom compression codecs

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
