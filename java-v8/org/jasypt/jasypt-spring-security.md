# jasypt-spring-security

> 标签: Java, Java 8+

## 简介

Jasypt integration with Spring Security (ACEGI).

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://www.jasypt.org

## 历史版本号

- 1.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/jasypt/jasypt-spring-security/
- Maven 坐标：`org.jasypt:jasypt-spring-security`
- pom.xml 引用：`<dependency><groupId>org.jasypt</groupId><artifactId>jasypt-spring-security</artifactId><version>1.1</version></dependency>`
- 源码仓库：http://jasypt.cvs.sourceforge.net/jasypt/
