# postgresql

> 标签: PostgreSQL, 数据库驱动, Java 8+

## 简介

PostgreSQL JDBC Driver Postgresql

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/postgresql/postgresql/
- Maven 坐标：`org.postgresql:postgresql`
- pom.xml 引用：`<dependency><groupId>org.postgresql</groupId><artifactId>postgresql</artifactId><version>42.7.13</version></dependency>`
- 源码仓库：https://github.com/pgjdbc/pgjdbc
