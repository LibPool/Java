# apache-jsieve-core

> 标签: Java, Java 8+

## 简介

Apache jSieve is a server side mail filtering system implementing RFC3028. Apache jSieve is developed by the James project.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
