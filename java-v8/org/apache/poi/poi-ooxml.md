# poi-ooxml

> 标签: Excel, Office, Word, Java 8+

## 简介

Apache POI - Java API To Access Microsoft Format Files

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/poi/poi-ooxml/
- Maven 坐标：`org.apache.poi:poi-ooxml`
- pom.xml 引用：`<dependency><groupId>org.apache.poi</groupId><artifactId>poi-ooxml</artifactId><version>5.5.1</version></dependency>`
