# commons-io

> 标签: IO, 工具库

## 简介

commons-io - Java library from Maven Central

## 官网

- https://central.sonatype.com/artifact/org.apache.commons%3Acommons-io

## 历史版本号

- 1.3.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/commons/commons-io/
- Maven 坐标：`org.apache.commons:commons-io`
- pom.xml 引用：`<dependency><groupId>org.apache.commons</groupId><artifactId>commons-io</artifactId><version>1.3.2</version></dependency>`
