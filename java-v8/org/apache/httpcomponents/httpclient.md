# httpclient

> 标签: HTTP客户端, Java 8+

## 简介

Apache HttpComponents Client

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/httpcomponents/httpclient/
- Maven 坐标：`org.apache.httpcomponents:httpclient`
- pom.xml 引用：`<dependency><groupId>org.apache.httpcomponents</groupId><artifactId>httpclient</artifactId><version>4.5.14</version></dependency>`
