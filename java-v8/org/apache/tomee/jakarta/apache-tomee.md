# apache-tomee

> 标签: Java, Java 8+

## 简介

Jakarta EE 9 version of Apache TomEE

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://tomee.apache.org

## 历史版本号

- 9.0.0-M1
- 9.0.0-M2
- 9.0.0-M3

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/tomee/jakarta/apache-tomee/
- Maven 坐标：`org.apache.tomee.jakarta:apache-tomee`
- pom.xml 引用：`<dependency><groupId>org.apache.tomee.jakarta</groupId><artifactId>apache-tomee</artifactId><version>9.0.0-M3</version></dependency>`
