# arquillian-jakarta-bom

> 标签: Java, Java 8+

## 简介

Arquillian Jakarta Bill Of Materials (BOM)

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://arquillian.org

## 历史版本号

- 1.8.1.Final
- 10.0.0.Final

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/jboss/arquillian/jakarta/arquillian-jakarta-bom/
- Maven 坐标：`org.jboss.arquillian.jakarta:arquillian-jakarta-bom`
- pom.xml 引用：`<dependency><groupId>org.jboss.arquillian.jakarta</groupId><artifactId>arquillian-jakarta-bom</artifactId><version>10.0.0.Final</version></dependency>`
