# spring-data-releasetrain

> 标签: github, Java 8+

## 简介

Bill of materials to make sure a consistent set of versions is used for Spring Data modules.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
