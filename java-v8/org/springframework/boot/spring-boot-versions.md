# spring-boot-versions

> 标签: Java, Java 8+

## 简介

Spring Boot Versions Property File

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/springframework/boot/spring-boot-versions/
- Maven 坐标：`org.springframework.boot:spring-boot-versions`
- pom.xml 引用：`<dependency><groupId>org.springframework.boot</groupId><artifactId>spring-boot-versions</artifactId><version>1.2.8.RELEASE</version></dependency>`
