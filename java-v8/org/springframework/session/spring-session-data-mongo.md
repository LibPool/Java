# spring-session-data-mongo

> 标签: github, Java 8+

## 简介

Aggregator for Spring Session and Spring Data Mongo

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
