# kotlinx-coroutines-core

> 标签: github, 协程, 异步编程, Java 8+

## 简介

Coroutines support libraries for Kotlin

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
