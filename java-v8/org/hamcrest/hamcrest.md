# hamcrest

> 标签: 断言, 测试, Java 8+

## 简介

Core API and libraries of hamcrest matcher framework.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/hamcrest/hamcrest/
- Maven 坐标：`org.hamcrest:hamcrest`
- pom.xml 引用：`<dependency><groupId>org.hamcrest</groupId><artifactId>hamcrest</artifactId><version>3.0</version></dependency>`
- 源码仓库：https://github.com/hamcrest/JavaHamcrest
