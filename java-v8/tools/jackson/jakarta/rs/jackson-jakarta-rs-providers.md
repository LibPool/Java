# jackson-jakarta-rs-providers

> 标签: github, Java 8+

## 简介

Parent for Jackson Jakarta-RS (jakarta.ws.rs) providers

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/tools/jackson/jakarta/rs/jackson-jakarta-rs-providers/
