# http-auth-spi

> 标签: Java, Java 8+

## 简介

The AWS SDK for Java - HTTP Auth SPI module contains the interfaces for authentication that are used by other modules in the library.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
