# tornimo-spring-cloud

> 标签: github, Java 8+

## 简介

Set of utilities for configuring Tornimo.io connector in the cloud.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/tornimo/tornimo-spring-cloud

## 历史版本号

- 0.0.1
- 0.3.0
- 0.3.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/tornimo/tornimo-spring-cloud/
- Maven 坐标：`io.tornimo:tornimo-spring-cloud`
- pom.xml 引用：`<dependency><groupId>io.tornimo</groupId><artifactId>tornimo-spring-cloud</artifactId><version>0.3.1</version></dependency>`
- 源码仓库：http://github.com/tornimo/tornimo-spring-cloud/tree/master
