# spring-boot-dependencies

> 标签: Java, Java 8+

## 简介

spring-boot-dependencies - Java library from Maven Central

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/io.kwy.boot%3Aspring-boot-dependencies

## 历史版本号

- 1.5.3.RELEASE
- 1.5.3.1.RELEASE

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/kwy/boot/spring-boot-dependencies/
- Maven 坐标：`io.kwy.boot:spring-boot-dependencies`
- pom.xml 引用：`<dependency><groupId>io.kwy.boot</groupId><artifactId>spring-boot-dependencies</artifactId><version>1.5.3.1.RELEASE</version></dependency>`
