## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/nats/nats-spring-boot-starter/
- Maven 坐标：`io.nats:nats-spring-boot-starter`
- pom.xml 引用：`<dependency><groupId>io.nats</groupId><artifactId>nats-spring-boot-starter</artifactId><version>0.6.2+3.5</version></dependency>`
