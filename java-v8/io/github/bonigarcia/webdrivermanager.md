# webdrivermanager

> 标签: 浏览器自动化, 驱动管理, Java 8+

## 简介

Automated driver management and other helper features for Selenium WebDriver in Java

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
