# commons-chain-web-jakarta-faces

> 标签: Java, Java 8+

## 简介

The web-part of commons-chain (jakarta-namespace).

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/io.github.weblegacy%3Acommons-chain-web-jakarta-faces

## 历史版本号

- 1.3.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/github/weblegacy/commons-chain-web-jakarta-faces/
