# admin-spring

> 标签: Java, Java 8+

## 简介

Admin api of ipokerface

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- Maven 仓库地址：https://repo.maven.apache.org/maven2/cn/ipokerface/admin-spring/
