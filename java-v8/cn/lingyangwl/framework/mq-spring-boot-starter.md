# mq-spring-boot-starter

> 标签: Java, Java 8+

## 简介

lingyang framework 适用所有java项目的公共库, 方便快速集成和使用, 提供工作效率

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- 1.3.0
