# spring-cloud-gray-plugins

> 标签: github, Java 8+

## 简介

Parent pom providing dependency and plugin management for applications built with Maven

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/cn/springcloud/gray/spring-cloud-gray-plugins/
- Maven 坐标：`cn.springcloud.gray:spring-cloud-gray-plugins`
- pom.xml 引用：`<dependency><groupId>cn.springcloud.gray</groupId><artifactId>spring-cloud-gray-plugins</artifactId><version>D.0.1.0-Beta-3</version></dependency>`
