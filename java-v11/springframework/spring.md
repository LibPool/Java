# spring

> 标签: Java, Java 8+

## 简介

spring - Java library from Maven Central

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/springframework/spring/
- Maven 坐标：`springframework:spring`
- pom.xml 引用：`<dependency><groupId>springframework</groupId><artifactId>spring</artifactId><version>1.2.6</version></dependency>`
