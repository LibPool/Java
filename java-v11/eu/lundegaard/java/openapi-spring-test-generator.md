# openapi-spring-test-generator

> 标签: github, Java 8+

## 简介

Parent POM of the OpenApi generator

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/lundegaard/openapi-spring-test-generator

## 历史版本号

- 1.0.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/eu/lundegaard/java/openapi-spring-test-generator/
- Maven 坐标：`eu.lundegaard.java:openapi-spring-test-generator`
- pom.xml 引用：`<dependency><groupId>eu.lundegaard.java</groupId><artifactId>openapi-spring-test-generator</artifactId><version>1.0.2</version></dependency>`
- 源码仓库：https://github.com/lundegaard/openapi-spring-test-generator.git
