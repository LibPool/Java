# selenium-java

> 标签: 测试, 浏览器自动化, Java 8+

## 简介

Selenium automates browsers. That's it! What you do with that power is entirely up to you.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
