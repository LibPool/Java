# org.beamfoundry.bundles.spring-data

> 标签: github, Java 8+

## 简介

This project provides Spring spring-data bundles for Apache Karaf.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/BeamFoundry/spring-data

## 历史版本号

- 1.4.4.RELEASE_1
- 1.4.4.RELEASE_2

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/beamfoundry/bundles/spring-data/org.beamfoundry.bundles.spring-data/
