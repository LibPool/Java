# kotlinx-serialization-json

> 标签: JSON, github, 序列化, Java 8+

## 简介

Kotlin multiplatform serialization runtime library

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
