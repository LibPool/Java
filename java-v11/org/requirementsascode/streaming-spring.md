# streaming-spring

> 标签: Java, Java 8+

## 简介

Message-driven microservices with little configuration.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://requirementsascode.org/

## 历史版本号

- 0.0.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/requirementsascode/streaming-spring/
- Maven 坐标：`org.requirementsascode:streaming-spring`
- pom.xml 引用：`<dependency><groupId>org.requirementsascode</groupId><artifactId>streaming-spring</artifactId><version>0.0.1</version></dependency>`
