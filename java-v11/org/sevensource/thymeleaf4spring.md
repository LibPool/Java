# thymeleaf4spring

> 标签: github, Java 8+

## 简介

Just some small utilities to quickly configure Thymeleaf with Spring MVC

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
