# reflections-spring

> 标签: Java, Java 8+

## 简介

Reflections Spring plugin

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.reflections%3Areflections-spring

## 历史版本号

- 0.9.9-RC1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/reflections/reflections-spring/
- Maven 坐标：`org.reflections:reflections-spring`
- pom.xml 引用：`<dependency><groupId>org.reflections</groupId><artifactId>reflections-spring</artifactId><version>0.9.9-RC1</version></dependency>`
