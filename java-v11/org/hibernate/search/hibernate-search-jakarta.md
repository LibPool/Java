# hibernate-search-jakarta

> 标签: Java, Java 8+

## 简介

Hibernate Search Aggregator POM for Jakarta EE Artifacts

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.hibernate.search%3Ahibernate-search-jakarta

## 历史版本号

- 6.1.0.Beta1
- 6.1.0.Beta2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/hibernate/search/hibernate-search-jakarta/
- Maven 坐标：`org.hibernate.search:hibernate-search-jakarta`
- pom.xml 引用：`<dependency><groupId>org.hibernate.search</groupId><artifactId>hibernate-search-jakarta</artifactId><version>6.1.0.Beta2</version></dependency>`
