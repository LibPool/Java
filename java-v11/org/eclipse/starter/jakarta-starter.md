# jakarta-starter

> 标签: github, Java 8+

## 简介

This is the official Eclipse Foundation Starter for Jakarta EE. It generates code to help get started with Jakarta EE projects. It is possible to do so using Maven archetypes.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
