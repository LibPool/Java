# exec-maven-plugin

> 标签: 构建插件, Java 8+

## 简介

A plugin to allow execution of system and Java programs

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/codehaus/mojo/exec-maven-plugin/
- Maven 坐标：`org.codehaus.mojo:exec-maven-plugin`
- pom.xml 引用：`<dependency><groupId>org.codehaus.mojo</groupId><artifactId>exec-maven-plugin</artifactId><version>3.6.4</version></dependency>`
- 源码仓库：https://github.com/mojohaus/exec-maven-plugin/tree/master
