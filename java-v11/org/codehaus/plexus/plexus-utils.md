# plexus-utils

> 标签: 工具库, Java 8+

## 简介

A collection of various utility classes to ease working with strings, files, command lines and more.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
