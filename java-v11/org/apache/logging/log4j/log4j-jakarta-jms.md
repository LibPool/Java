# log4j-jakarta-jms

> 标签: Java, Java 8+

## 简介

Apache Log4j Java Message Service (JMS), version for Jakarta.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://logging.apache.org/log4j/2.x/

- 2.25.3
- 2.25.4
- 2.25.5
- 2.26.0
- 2.26.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/logging/log4j/log4j-jakarta-jms/
- Maven 坐标：`org.apache.logging.log4j:log4j-jakarta-jms`
- pom.xml 引用：`<dependency><groupId>org.apache.logging.log4j</groupId><artifactId>log4j-jakarta-jms</artifactId><version>2.26.1</version></dependency>`
