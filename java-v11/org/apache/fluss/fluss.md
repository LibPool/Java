# fluss

> 标签: github, Java 8+

## 简介

Apache Fluss is a streaming storage system built for real-time analytics.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/apache/fluss

## 历史版本号

- 0.9.0-incubating
- 0.9.1-incubating
- 1.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/fluss/fluss/
