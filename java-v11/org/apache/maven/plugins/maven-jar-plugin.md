# maven-jar-plugin

> 标签: 构建插件, Java 8+

## 简介

Builds a Java Archive (JAR) file from the compiled project classes and resources.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
