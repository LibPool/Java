# apache-juneau

> 标签: Java, Java 8+

## 简介

Location to find fully built Juneau distributions.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.apache.juneau%3Aapache-juneau

## 历史版本号

- 6.0.0-incubating

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/juneau/apache-juneau/
- Maven 坐标：`org.apache.juneau:apache-juneau`
- pom.xml 引用：`<dependency><groupId>org.apache.juneau</groupId><artifactId>apache-juneau</artifactId><version>6.0.0-incubating</version></dependency>`
