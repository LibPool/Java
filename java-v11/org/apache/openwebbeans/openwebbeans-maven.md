# openwebbeans-maven

> 标签: Java, Java 8+

## 简介

Maven Shade Plugin Integration

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/openwebbeans/openwebbeans-maven/
- Maven 坐标：`org.apache.openwebbeans:openwebbeans-maven`
- pom.xml 引用：`<dependency><groupId>org.apache.openwebbeans</groupId><artifactId>openwebbeans-maven</artifactId><version>2.0.17</version></dependency>`
