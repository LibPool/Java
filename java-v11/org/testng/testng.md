# testng

> 标签: 单元测试, 测试, Java 11+

## 简介

Testing framework for Java

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/testng/testng/
- Maven 坐标：`org.testng:testng`
- pom.xml 引用：`<dependency><groupId>org.testng</groupId><artifactId>testng</artifactId><version>7.12.0</version></dependency>`
- 源码仓库：https://github.com/testng-team/testng.git
