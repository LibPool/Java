# spring-grpc-build-dependencies

> 标签: github, Java 8+

## 简介

Dependencies for the Spring gRPC modules

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/springframework/grpc/spring-grpc-build-dependencies/
- Maven 坐标：`org.springframework.grpc:spring-grpc-build-dependencies`
- pom.xml 引用：`<dependency><groupId>org.springframework.grpc</groupId><artifactId>spring-grpc-build-dependencies</artifactId><version>1.1.1</version></dependency>`
- 源码仓库：https://github.com/spring-projects/spring-grpc
