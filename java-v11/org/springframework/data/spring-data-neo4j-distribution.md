# spring-data-neo4j-distribution

> 标签: Java, Java 8+

## 简介

Distribution build for Spring Data Neo4j

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/springframework/data/spring-data-neo4j-distribution/
- Maven 坐标：`org.springframework.data:spring-data-neo4j-distribution`
- pom.xml 引用：`<dependency><groupId>org.springframework.data</groupId><artifactId>spring-data-neo4j-distribution</artifactId><version>5.3.9.RELEASE</version></dependency>`
