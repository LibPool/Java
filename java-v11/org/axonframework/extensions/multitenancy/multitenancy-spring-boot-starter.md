# multitenancy-spring-boot-starter

> 标签: Java, Java 8+

## 简介

Spring Boot Starter module for the Multi-Tenancy Extension of Axon Framework

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://axoniq.io

- 4.6.2
- 4.7.0
- 4.8.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/axonframework/extensions/multitenancy/multitenancy-spring-boot-starter/
- Maven 坐标：`org.axonframework.extensions.multitenancy:multitenancy-spring-boot-starter`
- pom.xml 引用：`<dependency><groupId>org.axonframework.extensions.multitenancy</groupId><artifactId>multitenancy-spring-boot-starter</artifactId><version>4.8.0</version></dependency>`
- 源码仓库：https://github.com/AxonFramework/extension-multitenancy
