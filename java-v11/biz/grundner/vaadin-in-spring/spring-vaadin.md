# spring-vaadin

> 标签: github, Java 8+

## 简介

Integrating Vaadin 7 with the Spring Framework

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/vaadin-in-spring/vaadin7

## 历史版本号

- 1.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/biz/grundner/vaadin-in-spring/spring-vaadin/
- Maven 坐标：`biz.grundner.vaadin-in-spring:spring-vaadin`
- pom.xml 引用：`<dependency><groupId>biz.grundner.vaadin-in-spring</groupId><artifactId>spring-vaadin</artifactId><version>1.0</version></dependency>`
- 源码仓库：https://github.com/vaadin-in-spring/vaadin7.git
