# spring-cloud-dependencies-parent

> 标签: Java, Java 8+

## 简介

此坐标为 pom ，源码可在商业版仓库下载。避免maven 循环依赖无实际意义

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
