> 标签: github, Java 8+

## 简介

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/tk/mybatis/mapper-spring-boot/
- Maven 坐标：`tk.mybatis:mapper-spring-boot`
- pom.xml 引用：`<dependency><groupId>tk.mybatis</groupId><artifactId>mapper-spring-boot</artifactId><version>6.0.0</version></dependency>`
