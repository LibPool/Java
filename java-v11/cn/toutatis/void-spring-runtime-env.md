# void-spring-runtime-env

> 标签: Java, Java 8+

## 简介

VOID 下 Spring Boot 运行环境支持

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://www.toutatis.cn/project/VOID

## 历史版本号

- 0.0.0-ALPHA

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/cn/toutatis/void-spring-runtime-env/
- Maven 坐标：`cn.toutatis:void-spring-runtime-env`
- pom.xml 引用：`<dependency><groupId>cn.toutatis</groupId><artifactId>void-spring-runtime-env</artifactId><version>0.0.0-ALPHA</version></dependency>`
