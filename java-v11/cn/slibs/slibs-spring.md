# slibs-spring

> 标签: github, Java 8+

## 简介

A Java library for Spring projects

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/cn/slibs/slibs-spring/

- pom.xml 引用：`<dependency><groupId>cn.slibs</groupId><artifactId>slibs-spring</artifactId><version>0.3.1</version></dependency>`
