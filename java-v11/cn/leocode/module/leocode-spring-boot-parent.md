# leocode-spring-boot-parent

> 标签: Java, Java 8+

## 简介

根据自定义请求头获取版本号，将响应数据重写为配置文件中配置的版本号对应的全局统一响应结构。

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://gitee.com/leocode-cn/response-version

## 历史版本号

- 2023.0.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/cn/leocode/module/leocode-spring-boot-parent/
- Maven 坐标：`cn.leocode.module:leocode-spring-boot-parent`
- pom.xml 引用：`<dependency><groupId>cn.leocode.module</groupId><artifactId>leocode-spring-boot-parent</artifactId><version>2023.0.0.0</version></dependency>`
- 源码仓库：https://gitee.com/leocode-cn/response-version
