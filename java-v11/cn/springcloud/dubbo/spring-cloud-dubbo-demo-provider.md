# spring-cloud-dubbo-demo-provider

> 标签: Java, Java 8+

## 简介

spring-cloud-dubbo-demo-provider is a service provider in this sample

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://springcloud.cn

## 历史版本号

- 1.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/cn/springcloud/dubbo/spring-cloud-dubbo-demo-provider/
- Maven 坐标：`cn.springcloud.dubbo:spring-cloud-dubbo-demo-provider`
- pom.xml 引用：`<dependency><groupId>cn.springcloud.dubbo</groupId><artifactId>spring-cloud-dubbo-demo-provider</artifactId><version>1.0.0</version></dependency>`
