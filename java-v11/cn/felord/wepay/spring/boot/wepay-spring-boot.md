# wepay-spring-boot

> 标签: Java, Java 8+

## 简介

Spring Boot Support for wePay

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://gitee.com/felord/wepay-spring-boot

## 历史版本号

- 1.0.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/cn/felord/wepay/spring/boot/wepay-spring-boot/
- Maven 坐标：`cn.felord.wepay.spring.boot:wepay-spring-boot`
- pom.xml 引用：`<dependency><groupId>cn.felord.wepay.spring.boot</groupId><artifactId>wepay-spring-boot</artifactId><version>1.0.2</version></dependency>`
