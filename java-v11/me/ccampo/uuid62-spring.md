# uuid62-spring

> 标签: github, Java 8+

## 简介

A small Kotlin library to convert UUIDs to Base62 encoded strings. Perfect for URLs!

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/ccampo133/uuid62

## 历史版本号

- 0.1.0
- 0.1.1

- Maven 仓库地址：https://repo.maven.apache.org/maven2/me/ccampo/uuid62-spring/

- pom.xml 引用：`<dependency><groupId>me.ccampo</groupId><artifactId>uuid62-spring</artifactId><version>0.1.1</version></dependency>`
