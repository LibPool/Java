# xingtools-spring-boot-starter

> 标签: Java, Java 8+

## 简介

xingtools 最终依赖包，该包是一个功能丰富的 Java工具库，通过诸多实用工具类的使用，旨在帮助开发者快速进行开发工作。 详见仓库 see repo: https://gitee.com/SangonomiyaKokomi/xingtools or https://github.com/cutexingluo/xingtools

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
