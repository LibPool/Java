# redis-tools

> 标签: github, Java 8+

## 简介

基于 Spring-data-redis 的 Redis 工具组件

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/spring-tools/redis-tools

## 历史版本号

- 1.0.0
- 1.1.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/github/spring-tools/redis-tools/
- Maven 坐标：`io.github.spring-tools:redis-tools`
- pom.xml 引用：`<dependency><groupId>io.github.spring-tools</groupId><artifactId>redis-tools</artifactId><version>1.1.0</version></dependency>`
- 源码仓库：https://github.com/spring-tools/redis-tools
