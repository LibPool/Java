# zuin-spring-jpa-filter

> 标签: github, Java 11+

## 简介

Library to simplify jpa filters

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/enayzuin

## 历史版本号

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/github/enayzuin/spring/jpa/filter/zuin-spring-jpa-filter/

- pom.xml 引用：`<dependency><groupId>io.github.enayzuin.spring.jpa.filter</groupId><artifactId>zuin-spring-jpa-filter</artifactId><version>1.0.0</version></dependency>`
- 源码仓库：https://github.com/enayzuin/spring-jpa-zuin-filter-library
