# jakarta-adapters

> 标签: Java, Java 11+

## 简介

An incomplete collection of classes for adapting Servlet API 4.0 objects to Servlet API 5.0 and vice versa.

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
