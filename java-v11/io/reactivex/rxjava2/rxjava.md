# rxjava

> 标签: github, 响应式编程, Java 8+

## 简介

Reactive Extensions for Java

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/reactivex/rxjava2/rxjava/
- Maven 坐标：`io.reactivex.rxjava2:rxjava`
- pom.xml 引用：`<dependency><groupId>io.reactivex.rxjava2</groupId><artifactId>rxjava</artifactId><version>2.2.21</version></dependency>`
