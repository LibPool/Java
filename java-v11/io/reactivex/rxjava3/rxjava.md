# rxjava

> 标签: github, 响应式编程, Java 8+

## 简介

Reactive Extensions for Java

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/reactivex/rxjava3/rxjava/
- Maven 坐标：`io.reactivex.rxjava3:rxjava`
- pom.xml 引用：`<dependency><groupId>io.reactivex.rxjava3</groupId><artifactId>rxjava</artifactId><version>3.1.12</version></dependency>`
- 源码仓库：https://github.com/ReactiveX/RxJava
