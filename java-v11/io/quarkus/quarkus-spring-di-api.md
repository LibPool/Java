# quarkus-spring-di-api

> 标签: Java, Java 8+

## 简介

The minimum dependencies to reduce the footprint of Quarkus applications using the Spring DI extension

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://quarkus.io/

## 历史版本号

- 5.1.Alpha1
- 5.2.Alpha1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/quarkus/quarkus-spring-di-api/

- pom.xml 引用：`<dependency><groupId>io.quarkus</groupId><artifactId>quarkus-spring-di-api</artifactId><version>5.2.Alpha1</version></dependency>`
