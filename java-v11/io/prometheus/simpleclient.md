# simpleclient

> 标签: 指标, 监控, Java 8+

## 简介

Core instrumentation library for the simpleclient.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- pom.xml 引用：`<dependency><groupId>io.prometheus</groupId><artifactId>simpleclient</artifactId><version>0.16.0</version></dependency>`
