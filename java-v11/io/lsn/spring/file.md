# file

> 标签: github, Java 8+

## 简介

File manager for spring application (file storage, file registry, application file service)

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/lsnova/spring-file

- 1.0.2

- 2.2.0
- 2.2.1
- 2.2.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/lsn/spring/file/
- Maven 坐标：`io.lsn.spring:file`
- pom.xml 引用：`<dependency><groupId>io.lsn.spring</groupId><artifactId>file</artifactId><version>2.2.2</version></dependency>`
- 源码仓库：https://github.com/lsnova/spring-file/tree/master
