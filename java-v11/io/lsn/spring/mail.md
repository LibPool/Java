# mail

> 标签: github, Java 8+

## 简介

Mailing service with scheduler, thymeleaf and attachments

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/lsnova/spring-mail

## 历史版本号

- 1.0.0
- 1.0.1
- 1.0.2
- 1.0.2b

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/lsn/spring/mail/
- Maven 坐标：`io.lsn.spring:mail`
- pom.xml 引用：`<dependency><groupId>io.lsn.spring</groupId><artifactId>mail</artifactId><version>1.0.2b</version></dependency>`
- 源码仓库：https://github.com/lsnova/spring-mail/tree/master
