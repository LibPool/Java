# bootique-jetty-jakarta-junit5

> 标签: Java, Java 11+

## 简介

JUnit 5 utilities to start Jetty 11 (Jakarta) on a dynamically determined port and provide a client that can be used by the tests

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
