# bootique-tapestry59-jakarta

> 标签: Java, Java 11+

## 简介

Provides Apache Tapestry 5.9.x Jakarta integration with Bootique.

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
