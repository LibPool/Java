# aurora-spring-boot-starter-parent

> 标签: github, Java 8+

## 简介

Parent for all aurora spring-boot-starters

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/no/skatteetaten/aurora/springboot/aurora-spring-boot-starter-parent/
- Maven 坐标：`no.skatteetaten.aurora.springboot:aurora-spring-boot-starter-parent`
- pom.xml 引用：`<dependency><groupId>no.skatteetaten.aurora.springboot</groupId><artifactId>aurora-spring-boot-starter-parent</artifactId><version>3.2.1</version></dependency>`
