# jakarta-httpcore

> 标签: Java, Java 8+

## 简介

Core components to build HTTP enabled services

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://jakarta.apache.org/httpcomponents/httpcore/

## 历史版本号

- 4.0-alpha1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/httpcomponents-httpcore/jakarta-httpcore/
- Maven 坐标：`httpcomponents-httpcore:jakarta-httpcore`
- pom.xml 引用：`<dependency><groupId>httpcomponents-httpcore</groupId><artifactId>jakarta-httpcore</artifactId><version>4.0-alpha1</version></dependency>`
- 源码仓库：http://svn.apache.org/repos/asf/jakarta/httpcomponents/httpcore/tags/4.0-alpha1/
