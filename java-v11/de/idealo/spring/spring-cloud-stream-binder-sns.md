# spring-cloud-stream-binder-sns

> 标签: github, Java 8+

## 简介

Allows you to use Spring Cloud Stream together with AWS SNS

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
