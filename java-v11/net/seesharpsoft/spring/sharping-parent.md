# sharping-parent

> 标签: github, Java 8+

## 简介

Programming model and libraries for developing WebApps on Java Spring Framework.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://github.com/seesharpsoft/sharping

- 0.8.0

- Maven 仓库地址：https://repo.maven.apache.org/maven2/net/seesharpsoft/spring/sharping-parent/
