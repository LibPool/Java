# spring-boost

> 标签: github, Java 8+

## 简介

Maven Archetype to generate a Spring Boot Application

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/shedhack/tool/spring-boost/
- Maven 坐标：`com.shedhack.tool:spring-boost`
- pom.xml 引用：`<dependency><groupId>com.shedhack.tool</groupId><artifactId>spring-boost</artifactId><version>3.0.0</version></dependency>`
