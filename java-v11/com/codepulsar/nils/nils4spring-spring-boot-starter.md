# nils4spring-spring-boot-starter

> 标签: Java, Java 8+

## 简介

Starter for the NILS integration into the Spring Framework

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/com.codepulsar.nils%3Anils4spring-spring-boot-starter

## 历史版本号

- 1.1.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/codepulsar/nils/nils4spring-spring-boot-starter/
- Maven 坐标：`com.codepulsar.nils:nils4spring-spring-boot-starter`
- pom.xml 引用：`<dependency><groupId>com.codepulsar.nils</groupId><artifactId>nils4spring-spring-boot-starter</artifactId><version>1.1.0</version></dependency>`
