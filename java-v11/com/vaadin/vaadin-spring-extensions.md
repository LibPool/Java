# vaadin-spring-extensions

> 标签: github, Java 8+

## 简介

Unofficial extensions for Vaadin Spring

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/vaadin/spring

## 历史版本号

- 4.0.0-beta.1
- 4.0.0
- 4.0.1
- 4.0.2
- 4.5.1-alpha1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/vaadin/vaadin-spring-extensions/
- Maven 坐标：`com.vaadin:vaadin-spring-extensions`
- pom.xml 引用：`<dependency><groupId>com.vaadin</groupId><artifactId>vaadin-spring-extensions</artifactId><version>4.5.1-alpha1</version></dependency>`
