# jakarta

> 标签: github, Java 11+

## 简介

SDK for integrating your Jakarta application with Queue-it

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/queue-it/connector/jakarta/

- pom.xml 引用：`<dependency><groupId>com.queue-it.connector</groupId><artifactId>jakarta</artifactId><version>4.4.3</version></dependency>`
- 源码仓库：http://github.com/queueit/connector-jakarta/tree/main
