# solace-spring-cloud-build

> 标签: github, Java 8+

## 简介

Build for Solace Spring Cloud support

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/solace/spring/cloud/solace-spring-cloud-build/
- Maven 坐标：`com.solace.spring.cloud:solace-spring-cloud-build`
- pom.xml 引用：`<dependency><groupId>com.solace.spring.cloud</groupId><artifactId>solace-spring-cloud-build</artifactId><version>6.1.0</version></dependency>`
- 源码仓库：https://github.com/SolaceProducts/solace-spring-cloud.git
