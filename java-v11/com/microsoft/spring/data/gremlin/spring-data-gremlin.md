# spring-data-gremlin

> 标签: github, Java 8+

## 简介

Gremlin support for Spring Data

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- pom.xml 引用：`<dependency><groupId>com.microsoft.spring.data.gremlin</groupId><artifactId>spring-data-gremlin</artifactId><version>2.3.0</version></dependency>`
