# spring-dbunit

> 标签: github, Java 8+

## 简介

A Spring integration for the DBUnit framework

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/excilys/spring-dbunit

## 历史版本号

- 1.4.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/excilys/ebi/spring-dbunit/spring-dbunit/
- Maven 坐标：`com.excilys.ebi.spring-dbunit:spring-dbunit`
- pom.xml 引用：`<dependency><groupId>com.excilys.ebi.spring-dbunit</groupId><artifactId>spring-dbunit</artifactId><version>1.4.0</version></dependency>`
- 源码仓库：https://github.com/excilys/spring-dbunit
