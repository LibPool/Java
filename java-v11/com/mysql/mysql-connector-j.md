# mysql-connector-j

> 标签: MySQL, 数据库驱动, Java 8+

## 简介

JDBC Type 4 driver for MySQL.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- http://dev.mysql.com/doc/connector-j/en/

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/mysql/mysql-connector-j/
- Maven 坐标：`com.mysql:mysql-connector-j`
- pom.xml 引用：`<dependency><groupId>com.mysql</groupId><artifactId>mysql-connector-j</artifactId><version>26.7.0</version></dependency>`
- 源码仓库：https://github.com/mysql/mysql-connector-j
