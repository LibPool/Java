# rest-recptcha-spring-boot-starter

> 标签: Java, Java 8+

## 简介

This is the starter project of the Rest Recaptcha project for Spring Boot.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/com.bsmoot%3Arest-recptcha-spring-boot-starter

## 历史版本号

- 1.0.0

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/bsmoot/rest-recptcha-spring-boot-starter/
