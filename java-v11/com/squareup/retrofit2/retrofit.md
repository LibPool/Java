# retrofit

> 标签: HTTP客户端, REST, github, Java 8+

## 简介

A type-safe HTTP client for Android and Java.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
