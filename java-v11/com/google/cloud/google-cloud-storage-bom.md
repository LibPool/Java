# google-cloud-storage-bom

> 标签: github, Java 8+

## 简介

BOM for Google Cloud Storage

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/google/cloud/google-cloud-storage-bom/
- Maven 坐标：`com.google.cloud:google-cloud-storage-bom`
- pom.xml 引用：`<dependency><groupId>com.google.cloud</groupId><artifactId>google-cloud-storage-bom</artifactId><version>2.75.0</version></dependency>`
- 源码仓库：https://github.com/googleapis/google-cloud-java
