# google-cloud-workflows

> 标签: github, Java 8+

## 简介

allows you to ochestrate and automate Google Cloud and HTTP-based API services with serverless workflows.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- pom.xml 引用：`<dependency><groupId>com.google.cloud</groupId><artifactId>google-cloud-workflows</artifactId><version>2.99.0</version></dependency>`
