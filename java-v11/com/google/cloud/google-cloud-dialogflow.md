# google-cloud-dialogflow

> 标签: github, Java 8+

## 简介

Java idiomatic client for Google Cloud Dialog Flow API

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- https://github.com/googleapis/google-cloud-java

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/google/cloud/google-cloud-dialogflow/
- Maven 坐标：`com.google.cloud:google-cloud-dialogflow`
- pom.xml 引用：`<dependency><groupId>com.google.cloud</groupId><artifactId>google-cloud-dialogflow</artifactId><version>4.105.0</version></dependency>`
