# appengine-api-legacy

> 标签: github, Java 8+

## 简介

Legacy appengine API's that have been removed from appengine-api-sdk-1.0

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/GoogleCloudPlatform/appengine-java-standard/

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/google/appengine/appengine-api-legacy/
- Maven 坐标：`com.google.appengine:appengine-api-legacy`
- pom.xml 引用：`<dependency><groupId>com.google.appengine</groupId><artifactId>appengine-api-legacy</artifactId><version>5.2.0-beta</version></dependency>`
