# gapic-generator-java-bom

> 标签: Java, Java 8+

## 简介

BOM for the libraries in gapic-generator-java repository. Users should not depend on this artifact explicitly because this BOM is an implementation detail of the Libraries BOM.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
