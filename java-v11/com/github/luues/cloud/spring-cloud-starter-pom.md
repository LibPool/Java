# spring-cloud-starter-pom

> 标签: github, Java 8+

## 简介

A simple jar reference based on spring cloud

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/luues/spring-luues/tree/master/spring-cloud/spring-cloud-starter-pom

## 历史版本号

- 1.0.0.0.RELEASE

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/github/luues/cloud/spring-cloud-starter-pom/
- Maven 坐标：`com.github.luues.cloud:spring-cloud-starter-pom`
- pom.xml 引用：`<dependency><groupId>com.github.luues.cloud</groupId><artifactId>spring-cloud-starter-pom</artifactId><version>1.0.0.0.RELEASE</version></dependency>`
- 源码仓库：https://github.com/luues/spring-luues/tree/master/spring-cloud/spring-cloud-starter-pom
