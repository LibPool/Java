# spring

> 标签: Java, Java 8+

## 简介

Spring runner for Mongock

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/com.github.cloudyrock.mongock%3Aspring

## 历史版本号

- 5.0.0.BETA
- 5.0.1.BETA

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/github/cloudyrock/mongock/spring/
- Maven 坐标：`com.github.cloudyrock.mongock:spring`
- pom.xml 引用：`<dependency><groupId>com.github.cloudyrock.mongock</groupId><artifactId>spring</artifactId><version>5.0.1.BETA</version></dependency>`
