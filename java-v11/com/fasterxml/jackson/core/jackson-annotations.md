# jackson-annotations

> 标签: JSON, 注解, Java 8+

## 简介

Core annotations used for value types, used by Jackson data binding package.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
