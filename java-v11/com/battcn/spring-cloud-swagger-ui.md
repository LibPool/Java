# spring-cloud-swagger-ui

> 标签: github, Java 8+

## 简介

一款采用VUE编写的swagger-ui

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/battcn/spring-cloud-swagger.git

## 历史版本号

- 1.0.0-RELEASE
- 1.0.1-RELEASE
- 1.0.2-RELEASE
- 1.0.3-RELEASE
- 1.0.4-RELEASE

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/battcn/spring-cloud-swagger-ui/
- Maven 坐标：`com.battcn:spring-cloud-swagger-ui`
- pom.xml 引用：`<dependency><groupId>com.battcn</groupId><artifactId>spring-cloud-swagger-ui</artifactId><version>1.0.4-RELEASE</version></dependency>`
