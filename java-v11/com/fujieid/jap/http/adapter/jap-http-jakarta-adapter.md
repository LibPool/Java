# jap-http-jakarta-adapter

> 标签: Java, Java 8+

## 简介

适配 jakarta.servlet-api 的 http 接口，包括：request、response、cookie、session

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
