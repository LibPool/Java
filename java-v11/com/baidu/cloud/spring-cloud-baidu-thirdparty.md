# spring-cloud-baidu-thirdparty

> 标签: github, Java 8+

## 简介

Spring Cloud Baidu Thirdparty Dependencies

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/baidu/spring-cloud-baidu

## 历史版本号

- 2022.2.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/baidu/cloud/spring-cloud-baidu-thirdparty/
- Maven 坐标：`com.baidu.cloud:spring-cloud-baidu-thirdparty`
- pom.xml 引用：`<dependency><groupId>com.baidu.cloud</groupId><artifactId>spring-cloud-baidu-thirdparty</artifactId><version>2022.2.0</version></dependency>`
- 源码仓库：https://github.com/baidu/spring-cloud-baidu.git
