# spring-data-aerospike-starters

> 标签: github, Java 8+

## 简介

Autoconfiguration project for Spring Data Aerospike

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/aerospike/spring-data-aerospike-starters/
- Maven 坐标：`com.aerospike:spring-data-aerospike-starters`
- pom.xml 引用：`<dependency><groupId>com.aerospike</groupId><artifactId>spring-data-aerospike-starters</artifactId><version>0.22.0</version></dependency>`
- 源码仓库：https://github.com/aerospike-community/spring-data-aerospike-starters
