# spring-multirabbit-parent

> 标签: github, Java 8+

## 简介

Library to extend Spring to provide connection to multiple RabbitMQ servers

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
