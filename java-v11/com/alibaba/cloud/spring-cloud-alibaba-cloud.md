# spring-cloud-alibaba-cloud

> 标签: Java, Java 8+

## 简介

spring boot starters and spring cloud starters for aliware

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://www.aliyun.com/product/edas

## 历史版本号

- 1.1.1
- 1.1.2
- 1.1.3

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/alibaba/cloud/spring-cloud-alibaba-cloud/
- Maven 坐标：`com.alibaba.cloud:spring-cloud-alibaba-cloud`
- pom.xml 引用：`<dependency><groupId>com.alibaba.cloud</groupId><artifactId>spring-cloud-alibaba-cloud</artifactId><version>1.1.3</version></dependency>`
- 源码仓库：http://svn.apache.org/viewvc/maven
