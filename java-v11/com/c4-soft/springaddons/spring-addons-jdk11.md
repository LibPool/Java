# spring-addons-jdk11

> 标签: github, Java 11+

## 简介

Set of tools I find useful to work with Spring (mostly spring-security for OpenID)

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
