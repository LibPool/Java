# picocli-spring-boot-starter

> 标签: github, Java 8+

## 简介

Spring boot starter for Picocli command line tools. Let you easily write CLI!

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/kakawait/picocli-spring-boot-starter

## 历史版本号

- 0.1.0
- 0.2.0
- 1.0.0-alpha-1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/kakawait/picocli-spring-boot-starter/
- Maven 坐标：`com.kakawait:picocli-spring-boot-starter`
- pom.xml 引用：`<dependency><groupId>com.kakawait</groupId><artifactId>picocli-spring-boot-starter</artifactId><version>1.0.0-alpha-1</version></dependency>`
- 源码仓库：https://github.com/kakawait/picocli-spring-boot-starter
