# treblle-jakarta

> 标签: github, Java 11+

## 简介

Official Treblle SDK for Javax Servlet API 5.0.0 and Javax RS API 3.0.0

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/Treblle/treblle-java

- 1.0.1
- 1.0.2
- 1.0.3
- 1.0.5

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/treblle/treblle-jakarta/
- Maven 坐标：`com.treblle:treblle-jakarta`
- pom.xml 引用：`<dependency><groupId>com.treblle</groupId><artifactId>treblle-jakarta</artifactId><version>1.0.5</version></dependency>`
- 源码仓库：https://github.com/Treblle/treblle-java/tree/main
