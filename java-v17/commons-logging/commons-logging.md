# commons-logging

> 标签: 日志, Java 8+

## 简介

Apache Commons Logging is a thin adapter allowing configurable bridging to other, well-known logging systems.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/commons-logging/commons-logging/
- Maven 坐标：`commons-logging:commons-logging`
- pom.xml 引用：`<dependency><groupId>commons-logging</groupId><artifactId>commons-logging</artifactId><version>1.4.0</version></dependency>`
- 源码仓库：https://gitbox.apache.org/repos/asf/commons-logging
