# drools-spring

> 标签: Java, Java 8+

## 简介

drools-spring - Java library from Maven Central

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/drools%3Adrools-spring

## 历史版本号

- 2.1
- 2.5-beta-1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/drools/drools-spring/
- Maven 坐标：`drools:drools-spring`
- pom.xml 引用：`<dependency><groupId>drools</groupId><artifactId>drools-spring</artifactId><version>2.5-beta-1</version></dependency>`
