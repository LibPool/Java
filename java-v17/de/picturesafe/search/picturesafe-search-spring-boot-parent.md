# picturesafe-search-spring-boot-parent

> 标签: github, Java 8+

## 简介

Starter for picturesafe-search based Spring Boot applications

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
