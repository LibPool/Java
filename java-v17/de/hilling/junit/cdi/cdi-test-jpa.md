# cdi-test-jpa

> 标签: Java, Java 11+

## 简介

jpa support for cdi-test, using cdi/weld integration

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

- 5.0.2

- Maven 仓库地址：https://repo.maven.apache.org/maven2/de/hilling/junit/cdi/cdi-test-jpa/
