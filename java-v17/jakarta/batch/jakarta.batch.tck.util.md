# jakarta.batch.tck.util

> 标签: Java, Java 11+

## 简介

General-purpose utility functionality for running the tests. Not specific to the Batch TCK. For example, it contains support for reporting and running the tests in separate Jakarta EE vehicles

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
