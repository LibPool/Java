# cdi-lite-tck-suite

> 标签: Java, Java 17+

## 简介

This module contains the TestNG suite.xml file to use to validate the CDI Lite tests from the CDI TCK

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
