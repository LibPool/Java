# hofund-spring

> 标签: Java, Java 17+

## 简介

A Spring-based module that provides tools to gather information about datasource and HTTP connections, enabling better monitoring and management of system components.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
