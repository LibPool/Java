# langchain4j-spring-bom

> 标签: github, Java 8+

## 简介

Bill of Materials POM for getting full, complete set of compatible versions of LangChain4j Spring modules

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/langchain4j/langchain4j-spring

- 1.0.0-beta1
- 1.0.0-beta2
- 1.0.0-beta3
- 1.0.0-beta4
- 1.0.0-beta5

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/dev/langchain4j/langchain4j-spring-bom/
- Maven 坐标：`dev.langchain4j:langchain4j-spring-bom`
- pom.xml 引用：`<dependency><groupId>dev.langchain4j</groupId><artifactId>langchain4j-spring-bom</artifactId><version>1.0.0-beta5</version></dependency>`
- 源码仓库：https://github.com/langchain4j/langchain4j-spring
