# martin-spring-boot-starter

> 标签: Java, Java 8+

## 简介

提供统一的业务开发starter，需要做扩展时，只需引入该stater即可

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/com.java2e%3Amartin-spring-boot-starter

## 历史版本号

- 1.0.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/java2e/martin-spring-boot-starter/
- Maven 坐标：`com.java2e:martin-spring-boot-starter`
- pom.xml 引用：`<dependency><groupId>com.java2e</groupId><artifactId>martin-spring-boot-starter</artifactId><version>1.0.2</version></dependency>`
