# modelmapper-spring-boot-starter

> 标签: github, Java 8+

## 简介

Spring Boot starter for ModelMapper

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/github/munerf/modelmapper-spring-boot-starter/modelmapper-spring-boot-starter/
