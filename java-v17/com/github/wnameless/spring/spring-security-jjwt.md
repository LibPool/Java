# spring-security-jjwt

> 标签: github, Java 8+

## 简介

Integrate the Java JSON Web Token(jjwt) library into Spring Security

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/wnameless/spring-security-jjwt

## 历史版本号

- 0.1.0
- 0.1.1
- 0.2.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/github/wnameless/spring/spring-security-jjwt/
- Maven 坐标：`com.github.wnameless.spring:spring-security-jjwt`
- pom.xml 引用：`<dependency><groupId>com.github.wnameless.spring</groupId><artifactId>spring-security-jjwt</artifactId><version>0.2.0</version></dependency>`
