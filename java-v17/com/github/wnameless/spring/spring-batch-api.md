# spring-batch-api

> 标签: github, Java 8+

## 简介

Add bulk operations support to any Spring RESTful API by a single annotation @EnableBulkApi.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/wnameless/spring-bulk-api

## 历史版本号

- 0.3.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/github/wnameless/spring/spring-batch-api/
- Maven 坐标：`com.github.wnameless.spring:spring-batch-api`
- pom.xml 引用：`<dependency><groupId>com.github.wnameless.spring</groupId><artifactId>spring-batch-api</artifactId><version>0.3.0</version></dependency>`
