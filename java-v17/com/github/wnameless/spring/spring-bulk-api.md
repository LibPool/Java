# spring-bulk-api

> 标签: github, Java 8+

## 简介

Add bulk operations support to any Spring RESTful API by a single annotation @EnableBulkApi.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
