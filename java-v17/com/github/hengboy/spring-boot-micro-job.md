# spring-boot-micro-job

> 标签: github, Java 8+

## 简介

spring-boot-micro-job 是一款分布式任务执行框架 核心组件： 1. 调度中心 2. 注册中心 3. 任务生产者 4. 任务消费者

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
