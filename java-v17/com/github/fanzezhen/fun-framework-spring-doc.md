# fun-framework-spring-doc

> 标签: github, Java 17+

## 简介

接口文档组件，基于 SpringDoc 生成 OpenAPI/Swagger 文档，访问路径为/swagger-ui/index.html

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
