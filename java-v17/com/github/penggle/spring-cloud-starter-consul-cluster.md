# spring-cloud-starter-consul-cluster

> 标签: Java, Java 8+

## 简介

cluster ConsulClient implementation for spring-cloud-consul(config、discovery、registry)

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网
