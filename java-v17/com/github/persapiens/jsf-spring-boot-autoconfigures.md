# jsf-spring-boot-autoconfigures

> 标签: Java, Java 8+

## 简介

Group of all JSF Spring Boot AutoConfigures

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/com.github.persapiens%3Ajsf-spring-boot-autoconfigures

## 历史版本号

- 1.7.3

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/github/persapiens/jsf-spring-boot-autoconfigures/
- Maven 坐标：`com.github.persapiens:jsf-spring-boot-autoconfigures`
- pom.xml 引用：`<dependency><groupId>com.github.persapiens</groupId><artifactId>jsf-spring-boot-autoconfigures</artifactId><version>1.7.3</version></dependency>`
