> 标签: ORM, github, 增强, Java 8+

## 简介

An powerful enhanced toolkit of MyBatis for simplify development

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
