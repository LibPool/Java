# kafkathena-jakarta

> 标签: github, Java 17+

## 简介

Create kafka producer and consumers via config files without config classes. Spring Boot 3.x/JDK17+

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/Trendyol

## 历史版本号

- 1.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/trendyol/kafkathena-jakarta/
- Maven 坐标：`com.trendyol:kafkathena-jakarta`
- pom.xml 引用：`<dependency><groupId>com.trendyol</groupId><artifactId>kafkathena-jakarta</artifactId><version>1.0.0</version></dependency>`
- 源码仓库：https://github.com/Trendyol/kafkathena-jakarta
