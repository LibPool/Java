# spark-spring

> 标签: github, Java 8+

## 简介

Provide support for Spring Context when using Spark Framework

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/rapatao/spark-spring

## 历史版本号

- 1.0.0
