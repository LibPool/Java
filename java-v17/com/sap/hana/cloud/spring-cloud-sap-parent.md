# spring-cloud-sap-parent

> 标签: github, Java 8+

## 简介

Spring Cloud Connectors for SAP HANA Cloud Platform (HCP) and SAP HANA DB platform

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/SAP/spring-cloud-sap

## 历史版本号

- 1.0.1.RELEASE
- 1.0.2.RELEASE
- 1.0.3.RELEASE
- 1.0.4.RELEASE

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/sap/hana/cloud/spring-cloud-sap-parent/
- Maven 坐标：`com.sap.hana.cloud:spring-cloud-sap-parent`
- pom.xml 引用：`<dependency><groupId>com.sap.hana.cloud</groupId><artifactId>spring-cloud-sap-parent</artifactId><version>1.0.4.RELEASE</version></dependency>`
