## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/structurizr/structurizr-spring/
- Maven 坐标：`com.structurizr:structurizr-spring`
- pom.xml 引用：`<dependency><groupId>com.structurizr</groupId><artifactId>structurizr-spring</artifactId><version>1.3.5</version></dependency>`
- 源码仓库：https://github.com/structurizr/java
