# jakarta-ee-webapp

> 标签: Java, Java 8+

## 简介

Maven archetype to JumpStart with JakartaEE project

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://www.sairaghava.com

## 历史版本号

- 1.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/sairaghava/jakarta-ee-webapp/
- Maven 坐标：`com.sairaghava:jakarta-ee-webapp`
- pom.xml 引用：`<dependency><groupId>com.sairaghava</groupId><artifactId>jakarta-ee-webapp</artifactId><version>1.0.0</version></dependency>`
- 源码仓库：https://gitlab.com/sairaghava_k/my-maven-archetypes
