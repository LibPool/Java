# spring-social-google

> 标签: github, Java 8+

## 简介

Google API for Spring Social

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/GabiAxel/spring-social-google

## 历史版本号

- 2.0.0.RELEASE

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/peertopark/spring/social/spring-social-google/

- 源码仓库：https://github.com/GabiAxel/spring-social-google
