# spring-multirabbit-parent

> 标签: Java, Java 8+

## 简介

Library to extend Spring to provide connection to multiple RabbitMQ servers

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://www.mytaxi.com

## 历史版本号

- 2.2.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/mytaxi/spring/multirabbit/spring-multirabbit-parent/
- Maven 坐标：`com.mytaxi.spring.multirabbit:spring-multirabbit-parent`
- pom.xml 引用：`<dependency><groupId>com.mytaxi.spring.multirabbit</groupId><artifactId>spring-multirabbit-parent</artifactId><version>2.2.0</version></dependency>`
