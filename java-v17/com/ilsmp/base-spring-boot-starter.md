# base-spring-boot-starter

> 标签: Java, Java 11+

## 简介

springBoot项目基础框架集成,解决各种微服务组件兼容性问题,详细使用查看README.md

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
