# zenvia-api-sdk-starter-client-spring

> 标签: Java, Java 8+

## 简介

Starter for building Zenvia API Client using Spring

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
