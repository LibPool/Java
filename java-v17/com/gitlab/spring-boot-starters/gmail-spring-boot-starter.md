# gmail-spring-boot-starter

> 标签: Java, Java 8+

## 简介

A spring boot starter used to set up spring mail sender using Gmail API

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://gitlab.com/spring-boot-starters/gmail-spring-boot-starter

## 历史版本号

- 1.0.5.RELEASE

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/gitlab/spring-boot-starters/gmail-spring-boot-starter/
- Maven 坐标：`com.gitlab.spring-boot-starters:gmail-spring-boot-starter`
- pom.xml 引用：`<dependency><groupId>com.gitlab.spring-boot-starters</groupId><artifactId>gmail-spring-boot-starter</artifactId><version>1.0.5.RELEASE</version></dependency>`
- 源码仓库：https://gitlab.com/spring-boot-starters/gmail-spring-boot-starter
