# jmemcached-parent

> 标签: github, Java 8+

## 简介

Caching server speaking the memcached protocol, written in Java.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/ragnor/jmemcache-daemon

## 历史版本号

- 1.0.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/google/code/simple-spring-memcached/jmemcached-parent/
- Maven 坐标：`com.google.code.simple-spring-memcached:jmemcached-parent`
- pom.xml 引用：`<dependency><groupId>com.google.code.simple-spring-memcached</groupId><artifactId>jmemcached-parent</artifactId><version>1.0.2</version></dependency>`
