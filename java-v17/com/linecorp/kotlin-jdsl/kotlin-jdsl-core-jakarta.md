# kotlin-jdsl-core-jakarta

> 标签: github, Java 17+

## 简介

DSL for JPA Criteria API without generated metamodel and reflection.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/line/kotlin-jdsl

## 历史版本号

- 2.1.0.RELEASE
- 2.2.0.RELEASE
- 2.2.1.RELEASE
