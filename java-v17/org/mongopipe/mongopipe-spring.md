# mongopipe-spring

> 标签: github, Java 8+

## 简介

Run and manage MongoDB pipelines. Stores pipelines in the database, binds them to user own interface methods in the code.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/MongoPipe/mongopipe-spring

## 历史版本号

- 1.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/mongopipe/mongopipe-spring/
- Maven 坐标：`org.mongopipe:mongopipe-spring`
- pom.xml 引用：`<dependency><groupId>org.mongopipe</groupId><artifactId>mongopipe-spring</artifactId><version>1.0.0</version></dependency>`
