# org.apache.maven

> 标签: Java, Java 8+

## 简介

Maven POM schemas. Basic schema bindings for 3.0 and 4.0 poms.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/jibx/schema/org/apache/maven/org.apache.maven/
- Maven 坐标：`org.jibx.schema.org.apache.maven:org.apache.maven`
- pom.xml 引用：`<dependency><groupId>org.jibx.schema.org.apache.maven</groupId><artifactId>org.apache.maven</artifactId><version>1.2.6</version></dependency>`
