# appfuse-spring

> 标签: Java, Java 8+

## 简介

Spring MVC Module for AppFuse: includes Spring MVC, Display Tag and Spring Modules for validation.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://source.appfuse.org/browse/appfuse/web/spring

## 历史版本号

- 3.0.0
- 3.5.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/appfuse/appfuse-spring/

- pom.xml 引用：`<dependency><groupId>org.appfuse</groupId><artifactId>appfuse-spring</artifactId><version>3.5.0</version></dependency>`
