# lra-service-base-jakarta

> 标签: Java, Java 11+

## 简介

Provides a base module for the functionality shared between LRA coordination and LRA clients

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
