# resteasy-spring-jetty

> 标签: Java, Java 8+

## 简介

Resteasy Spring Jetty integration

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.jboss.resteasy%3Aresteasy-spring-jetty

## 历史版本号

- 2.3.10.Final

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/jboss/resteasy/resteasy-spring-jetty/
