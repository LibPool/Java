# arquillian-parent-jakarta

> 标签: Java, Java 11+

## 简介

Jakarta protocols and testenrichers for the Arquillian Project

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- git://github.com/arquillian/arquillian-jakarta.git

## 历史版本号

- 1.8.0.Final
- 1.8.1.Final
- 10.0.0.Final

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/jboss/arquillian/jakarta/arquillian-parent-jakarta/
- Maven 坐标：`org.jboss.arquillian.jakarta:arquillian-parent-jakarta`
- pom.xml 引用：`<dependency><groupId>org.jboss.arquillian.jakarta</groupId><artifactId>arquillian-parent-jakarta</artifactId><version>10.0.0.Final</version></dependency>`
