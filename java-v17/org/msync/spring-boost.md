# spring-boost

> 标签: github, Java 8+

## 简介

Just add dependency, sprinkle some config, and run Clojure in your Springboot application.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/jaju/spring-boost

## 历史版本号

- 0.2.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/msync/spring-boost/
- Maven 坐标：`org.msync:spring-boost`
- pom.xml 引用：`<dependency><groupId>org.msync</groupId><artifactId>spring-boost</artifactId><version>0.2.0</version></dependency>`
- 源码仓库：https://github.com/jaju/spring-boost
