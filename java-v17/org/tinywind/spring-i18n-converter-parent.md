# spring-i18n-converter-parent

> 标签: github, Java 8+

## 简介

Spring's message_?(\[a-zA-Z_\]+)?.properties convert to JS file

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
