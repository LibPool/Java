# org.beamfoundry.bundles.spring-osgi

> 标签: github, Java 8+

## 简介

This project provides spring-dm 1.2+ component to Apache Karaf for Spring version 4 and above.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/BeamFoundry/spring-osgi

## 历史版本号

- 1.3.0
- 1.3.1
