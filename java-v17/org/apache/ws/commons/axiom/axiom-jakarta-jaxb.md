# axiom-jakarta-jaxb

> 标签: Java, Java 11+

## 简介

Provides an OMDataSource implementation for JAXB 2.x.

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://ws.apache.org/axiom/

## 历史版本号

- 2.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/ws/commons/axiom/axiom-jakarta-jaxb/
- Maven 坐标：`org.apache.ws.commons.axiom:axiom-jakarta-jaxb`
- pom.xml 引用：`<dependency><groupId>org.apache.ws.commons.axiom</groupId><artifactId>axiom-jakarta-jaxb</artifactId><version>2.0.0</version></dependency>`
