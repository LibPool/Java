# cloud

> 标签: Java, Java 8+

## 简介

Group of modules for reading and writing data from/to the cloud. This module provides virtual file systems that `sis-storage` modules can use.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.apache.sis%3Acloud

## 历史版本号

- 1.2
- 1.3

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/sis/cloud/
- Maven 坐标：`org.apache.sis:cloud`
- pom.xml 引用：`<dependency><groupId>org.apache.sis</groupId><artifactId>cloud</artifactId><version>1.3</version></dependency>`
