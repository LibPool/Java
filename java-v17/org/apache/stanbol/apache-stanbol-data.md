# apache-stanbol-data

> 标签: Java, Java 8+

## 简介

Pseudo project to build the complete Apache Stanbol Data bundles

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- 1.1.0
- 1.2.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/stanbol/apache-stanbol-data/
- Maven 坐标：`org.apache.stanbol:apache-stanbol-data`
- pom.xml 引用：`<dependency><groupId>org.apache.stanbol</groupId><artifactId>apache-stanbol-data</artifactId><version>1.2.0</version></dependency>`
