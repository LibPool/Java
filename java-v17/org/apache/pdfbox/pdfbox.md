# pdfbox

> 标签: PDF, 文档处理, Java 8+

## 简介

The Apache PDFBox library is an open source Java tool for working with PDF documents.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
