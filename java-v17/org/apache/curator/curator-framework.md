# curator-framework

> 标签: ZooKeeper, 分布式协调, Java 8+

## 简介

High-level API that greatly simplifies using ZooKeeper.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
