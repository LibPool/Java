# fluss-protogen

> 标签: Java, Java 8+

## 简介

ProtoGen is a protobuf compatible code generator which is used to generate Java code for the RPC messages between Fluss server and client. The code is a modified version of the Splunk Lightproto project to match to needs of Fluss. ProtoGen maintains a fork of Lightproto in the Fluss repository, because Splunk Lightproto has been archived: https://github.com/splunk/lightproto.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
