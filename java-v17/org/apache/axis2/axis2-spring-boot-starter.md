# axis2-spring-boot-starter

> 标签: Java, Java 17+

## 简介

Spring Boot autoconfiguration for Apache Axis2. Add this single dependency to get AxisServlet registered, repository staged, and OpenAPI/MCP endpoints activated with sensible defaults. Supports both SOAP and JSON-RPC modes via axis2.mode property.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
