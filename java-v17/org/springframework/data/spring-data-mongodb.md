# spring-data-mongodb

> 标签: Java, Java 17+

## 简介

MongoDB support for Spring Data

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

- Maven 坐标：`org.springframework.data:spring-data-mongodb`
- pom.xml 引用：`<dependency><groupId>org.springframework.data</groupId><artifactId>spring-data-mongodb</artifactId><version>5.2.0-M1</version></dependency>`
