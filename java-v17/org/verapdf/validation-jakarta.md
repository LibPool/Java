# validation-jakarta

> 标签: github, Java 8+

## 简介

veraPDF validation, feature extraction and metadata repair with Jakarta EE support.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
