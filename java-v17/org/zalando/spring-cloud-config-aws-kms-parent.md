# spring-cloud-config-aws-kms-parent

> 标签: github, Java 8+

## 简介

Spring Cloud Config add-on that provides encryption via AWS KMS

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
