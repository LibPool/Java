# hibernate-testing-jakarta

> 标签: Java, Java 8+

## 简介

Support for testing Hibernate ORM Jakarta functionality

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://hibernate.org/orm

## 历史版本号

- 6.0.0.Alpha9

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/hibernate/orm/hibernate-testing-jakarta/
- Maven 坐标：`org.hibernate.orm:hibernate-testing-jakarta`
- pom.xml 引用：`<dependency><groupId>org.hibernate.orm</groupId><artifactId>hibernate-testing-jakarta</artifactId><version>6.0.0.Alpha9</version></dependency>`
- 源码仓库：https://github.com/hibernate/hibernate-orm
