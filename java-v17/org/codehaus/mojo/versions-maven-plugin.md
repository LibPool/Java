# versions-maven-plugin

> 标签: 构建插件, Java 8+

## 简介

The Versions Maven Plugin is used when you want to manage the versions of artifacts in a project's POM.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
