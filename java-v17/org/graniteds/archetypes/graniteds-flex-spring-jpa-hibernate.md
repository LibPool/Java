# graniteds-flex-spring-jpa-hibernate

> 标签: Java, Java 8+

## 简介

Base project with Flex 4.6, Spring 3 and Hibernate using GraniteDS with RemoteObject API.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
