# activemix-xbean-spring

> 标签: Java, Java 8+

## 简介

XBean Spring put on Spring 4.3.x.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.apifocal.activemix.xbean%3Aactivemix-xbean-spring
