# neo4j-ogm-spring-parent

> 标签: Java, Java 17+

## 简介

Neo4j support for Spring Data

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/neo4j/neo4j-ogm-spring-parent/
- Maven 坐标：`org.neo4j:neo4j-ogm-spring-parent`
- pom.xml 引用：`<dependency><groupId>org.neo4j</groupId><artifactId>neo4j-ogm-spring-parent</artifactId><version>2.1.2</version></dependency>`
