# vertx-spring-ext-8

> 标签: github, Java 8+

## 简介

This vertx extension adds spring capabilities by annotating an Vertx class (verticle) with @SpringVerticle.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/amoAHCP/spring-vertx

## 历史版本号

- 2.4

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/jacpfx/vertx/spring/vertx-spring-ext-8/
