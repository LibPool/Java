# spring-jdbc

> 标签: github, Java 8+

## 简介

一个简单的jdbc封装库，大多数api接口与spring-jdbc类似

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/luokaiqiongmou/spring-jdbc

## 历史版本号

- 1.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/me/mario6/spring-jdbc/
- Maven 坐标：`me.mario6:spring-jdbc`
- pom.xml 引用：`<dependency><groupId>me.mario6</groupId><artifactId>spring-jdbc</artifactId><version>1.0</version></dependency>`
- 源码仓库：https://github.com/luokaiqiongmou/spring-jdbc
