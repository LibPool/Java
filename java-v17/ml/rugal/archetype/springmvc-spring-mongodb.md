# springmvc-spring-mongodb

> 标签: Java, Java 8+

## 简介

An archetype based on springmvc spring and MongoDB

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://rugal.ga/

## 历史版本号

- 0.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/ml/rugal/archetype/springmvc-spring-mongodb/
- Maven 坐标：`ml.rugal.archetype:springmvc-spring-mongodb`
- pom.xml 引用：`<dependency><groupId>ml.rugal.archetype</groupId><artifactId>springmvc-spring-mongodb</artifactId><version>0.1</version></dependency>`
