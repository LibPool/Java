# spring-boot-starter-solace-client-config

> 标签: Java, Java 17+

## 简介

Provides functionality to define solace client certificate PEM text and private key directly in env variables or yaml files instead of using jks files.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
