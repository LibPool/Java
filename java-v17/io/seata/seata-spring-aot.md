# seata-spring-aot

> 标签: Java, Java 8+

## 简介

spring-aot top parent for Seata built with Maven

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/io.seata%3Aseata-spring-aot

## 历史版本号

- 1.7.0
- 1.7.0-native-rc2
- 1.7.1
- 1.8.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/seata/seata-spring-aot/
- Maven 坐标：`io.seata:seata-spring-aot`
- pom.xml 引用：`<dependency><groupId>io.seata</groupId><artifactId>seata-spring-aot</artifactId><version>1.8.0</version></dependency>`
