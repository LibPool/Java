# bootique-jersey-jakarta

> 标签: Java, Java 11+

## 简介

Provides Jersey 3 (Jakarta) integration with Bootique

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/bootique/jersey/bootique-jersey-jakarta/
