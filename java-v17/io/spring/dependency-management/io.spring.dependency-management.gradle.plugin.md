# io.spring.dependency-management.gradle.plugin

> 标签: github, Java 8+

## 简介

A Gradle plugin that provides Maven-like dependency management functionality

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
