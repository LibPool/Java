# jakarta-fileupload

> 标签: github, Java 17+

## 简介

Apache Common File Upload 1.5 built with Java 17 support.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 官网

- http://github.com/HugoMario/jakarta-fileupload/

## 历史版本号

- 1.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/github/hugomario/jakarta-fileupload/
- Maven 坐标：`io.github.hugomario:jakarta-fileupload`
- pom.xml 引用：`<dependency><groupId>io.github.hugomario</groupId><artifactId>jakarta-fileupload</artifactId><version>1.0.0</version></dependency>`
- 源码仓库：http://github.com/HugoMario/jakarta-fileupload/tree/main
