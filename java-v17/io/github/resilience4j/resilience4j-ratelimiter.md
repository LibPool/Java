# resilience4j-ratelimiter

> 标签: 容错, 限流, Java 17+

## 简介

Resilience4j is a lightweight, easy-to-use fault tolerance library designed for Java8 and functional programming

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
