# uid-reactive-generator-spring

> 标签: github, Java 17+

## 简介

UidGenerator is a Java implemented, Snowflake based unique ID generator.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

- 1.2.2
