# spring-plugins

## 简介

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- https://central.sonatype.com/artifact/io.github.thebesteric.framework.apm.agent.plugins%3Aspring-plugins

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/github/thebesteric/framework/apm/agent/plugins/spring-plugins/
