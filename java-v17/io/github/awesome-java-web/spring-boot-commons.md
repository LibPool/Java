# spring-boot-commons

> 标签: github, Java 8+

## 简介

Spring Boot Commons 是一套基于 Spring Boot 框架的可重用 Java 代码和模块，旨在简化和增强 Spring Boot 应用的开发过程

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
