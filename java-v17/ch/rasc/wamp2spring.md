# wamp2spring

> 标签: github, Java 8+

## 简介

Implementation of WAMP v2 based on the Spring 5 websocket support

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/ralscha/wamp2spring/

## 历史版本号

- 1.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/ch/rasc/wamp2spring/
- Maven 坐标：`ch.rasc:wamp2spring`
- pom.xml 引用：`<dependency><groupId>ch.rasc</groupId><artifactId>wamp2spring</artifactId><version>1.0.0</version></dependency>`
- 源码仓库：https://github.com/ralscha/wamp2spring.git
