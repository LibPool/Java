# spring-json

> 标签: Java, Java 8+

## 简介

Spring Json-View adds JavaScript Object Notation (json) support to Spring-MVC

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://spring-json.sourceforge.net/

## 历史版本号

- 1.3.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/net/sf/spring-json/spring-json/
- Maven 坐标：`net.sf.spring-json:spring-json`
- pom.xml 引用：`<dependency><groupId>net.sf.spring-json</groupId><artifactId>spring-json</artifactId><version>1.3.1</version></dependency>`
- 源码仓库：http://spring-json.svn.sourceforge.net/viewvc/spring-json
