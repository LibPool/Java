# sticky-composite-jersey-spring

> 标签: Java, Java 8+

## 简介

Composition of dependencies for using jersey1 with spring3

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://www.StickyCode.net/composite/sticky-composite-jersey-spring/

## 历史版本号

- 1.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/net/stickycode/composite/sticky-composite-jersey-spring/
- Maven 坐标：`net.stickycode.composite:sticky-composite-jersey-spring`
- pom.xml 引用：`<dependency><groupId>net.stickycode.composite</groupId><artifactId>sticky-composite-jersey-spring</artifactId><version>1.1</version></dependency>`
