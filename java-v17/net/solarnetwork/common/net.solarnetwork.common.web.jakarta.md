# net.solarnetwork.common.web.jakarta

> 标签: github, Java 17+

## 简介

Common supporting infrastructure for SolarNode and SolarNet web applications using Jakarta EE.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
