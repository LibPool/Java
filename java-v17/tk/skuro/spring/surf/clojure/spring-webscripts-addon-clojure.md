# spring-webscripts-addon-clojure

> 标签: github, Java 8+

## 简介

Support Clojure controllers for Spring Surf applications

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/skuro/spring-webscripts-addon-clojure/

## 历史版本号

- 1.0-alpha1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/tk/skuro/spring/surf/clojure/spring-webscripts-addon-clojure/
- Maven 坐标：`tk.skuro.spring.surf.clojure:spring-webscripts-addon-clojure`
- pom.xml 引用：`<dependency><groupId>tk.skuro.spring.surf.clojure</groupId><artifactId>spring-webscripts-addon-clojure</artifactId><version>1.0-alpha1</version></dependency>`
- 源码仓库：https://github.com/skuro/spring-webscripts-addon-clojure
