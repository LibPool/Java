# mapper-spring

> 标签: github, Java 17+

## 简介

Mybatis 通用 Mapper 和 Spring 集成

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/tk/mybatis/mapper-spring/
- Maven 坐标：`tk.mybatis:mapper-spring`
- pom.xml 引用：`<dependency><groupId>tk.mybatis</groupId><artifactId>mapper-spring</artifactId><version>6.0.0</version></dependency>`
