# unitils-spring-batch

> 标签: Java, Java 8+

## 简介

Unitils module to test spring batches.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://sourceforge.net/projects/unitilsspringbatch/

## 历史版本号

- 1.0.1
- 1.0.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/unitils/spring/batch/unitils-spring-batch/
- Maven 坐标：`org.unitils.spring.batch:unitils-spring-batch`
- pom.xml 引用：`<dependency><groupId>org.unitils.spring.batch</groupId><artifactId>unitils-spring-batch</artifactId><version>1.0.2</version></dependency>`
- 源码仓库：https://svn.code.sf.net/p/unitilsspringbatch/code/tags/unitils-spring-batch-1.0.2
