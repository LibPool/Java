# rest-spring

> 标签: Java, Java 8+

## 简介

AndroidAnnotations plugin for REST with Spring REST template

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/androidannotations/rest-spring/
- Maven 坐标：`org.androidannotations:rest-spring`
- pom.xml 引用：`<dependency><groupId>org.androidannotations</groupId><artifactId>rest-spring</artifactId><version>4.8.0</version></dependency>`
