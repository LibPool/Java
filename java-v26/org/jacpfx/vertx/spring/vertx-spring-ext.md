# vertx-spring-ext

> 标签: github, Java 11+

## 简介

This vertx extension adds spring capabilities by annotating an Vertx class (verticle) with @SpringVerticle.

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
