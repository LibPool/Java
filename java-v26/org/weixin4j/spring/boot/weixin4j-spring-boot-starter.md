# weixin4j-spring-boot-starter

> 标签: github, Java 8+

## 简介

一个让Weixin4j可以在SpringBoot2.0中集成的框架。

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/ansitech/weixin4j-spring-boot-starter

## 历史版本号

- 1.0.0
- 2.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/weixin4j/spring/boot/weixin4j-spring-boot-starter/
- Maven 坐标：`org.weixin4j.spring.boot:weixin4j-spring-boot-starter`
- pom.xml 引用：`<dependency><groupId>org.weixin4j.spring.boot</groupId><artifactId>weixin4j-spring-boot-starter</artifactId><version>2.0.0</version></dependency>`
- 源码仓库：https://github.com/ansitech/weixin4j-spring-boot-starter
