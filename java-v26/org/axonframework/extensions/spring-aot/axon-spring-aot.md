# axon-spring-aot

> 标签: Java, Java 17+

## 简介

Extension for Axon Framework providing support for Spring's Ahead of Time optimizations.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/axonframework/extensions/spring-aot/axon-spring-aot/

- pom.xml 引用：`<dependency><groupId>org.axonframework.extensions.spring-aot</groupId><artifactId>axon-spring-aot</artifactId><version>4.12.0</version></dependency>`
