# spring-data-neo4j

> 标签: Java, Java 8+

## 简介

Next generation Object-Graph-Mapping for Spring Data.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
