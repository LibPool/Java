# maven-spring-skin

> 标签: Java, Java 8+

## 简介

A Maven2 Skin that resembles the layout of www.springframework.org

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
