# spring-boot-starter-pulsar-reactive

> 标签: Java, Java 17+

## 简介

Starter for using Spring for Apache Pulsar Reactive

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
