# spring-ldap-ldif

> 标签: Java, Java 8+

## 简介

This packages provides an LDIF Parser for use with the Spring LDAP suite of utilities.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.springframework.ldap.ldif%3Aspring-ldap-ldif

## 历史版本号

- 1.3.1.RELEASE

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/springframework/ldap/ldif/spring-ldap-ldif/
- Maven 坐标：`org.springframework.ldap.ldif:spring-ldap-ldif`
- pom.xml 引用：`<dependency><groupId>org.springframework.ldap.ldif</groupId><artifactId>spring-ldap-ldif</artifactId><version>1.3.1.RELEASE</version></dependency>`
