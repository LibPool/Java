# shapeshifter-spring

> 标签: Java, Java 21+

## 简介

Connect your Spring Boot application easily to Shapeshifter library.

最低 Java 版本：Java 21；已收录于 java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/lfenergy/shapeshifter/shapeshifter-spring/
- Maven 坐标：`org.lfenergy.shapeshifter:shapeshifter-spring`
- pom.xml 引用：`<dependency><groupId>org.lfenergy.shapeshifter</groupId><artifactId>shapeshifter-spring</artifactId><version>3.6.0</version></dependency>`
