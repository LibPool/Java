# spring-boot

> 标签: Java, Java 17+

## 简介

JoinedWorkz facility for generating Spring Boot persistence, REST API providers, database migrations, and integration tests.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
