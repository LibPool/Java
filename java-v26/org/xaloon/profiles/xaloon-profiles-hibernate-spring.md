# xaloon-profiles-hibernate-spring

> 标签: Java, Java 8+

## 简介

xaloon profile, which adds such dependencies: spring for DI, spring security, hibernate as ORM

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
