# apache-jar-resource-bundle

> 标签: Java, Java 8+

## 简介

An archive which contains templates for generating the necessary license files and notices for all Apache releases.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.apache.apache.resources%3Aapache-jar-resource-bundle

## 历史版本号

- 1.5
- 1.7
- 1.8

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/apache/resources/apache-jar-resource-bundle/
- Maven 坐标：`org.apache.apache.resources:apache-jar-resource-bundle`
- pom.xml 引用：`<dependency><groupId>org.apache.apache.resources</groupId><artifactId>apache-jar-resource-bundle</artifactId><version>1.8</version></dependency>`
