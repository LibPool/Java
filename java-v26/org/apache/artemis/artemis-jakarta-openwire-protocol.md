# artemis-jakarta-openwire-protocol

> 标签: Java, Java 17+

## 简介

To support OpenWire clients from an embedded broker deployed in a Jakarta environment (e.g. Spring Boot 3)

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
