# commons-email2-jakarta

> 标签: Java, Java 8+

## 简介

Apache Commons Email provides an API for sending email, simplifying the JavaMail Javax API.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.apache.commons%3Acommons-email2-jakarta

## 历史版本号

- 2.0.0-M1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/commons/commons-email2-jakarta/
- Maven 坐标：`org.apache.commons:commons-email2-jakarta`
- pom.xml 引用：`<dependency><groupId>org.apache.commons</groupId><artifactId>commons-email2-jakarta</artifactId><version>2.0.0-M1</version></dependency>`
