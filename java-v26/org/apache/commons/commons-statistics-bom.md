# commons-statistics-bom

> 标签: Java, Java 8+

## 简介

Bill of Materials (BOM) to aid in dependency management when referencing multiple Apache Commons Statistics artifacts.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://commons.apache.org/proper/commons-statistics/

## 历史版本号

- 1.1
- 1.2
- 1.3

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/commons/commons-statistics-bom/
- Maven 坐标：`org.apache.commons:commons-statistics-bom`
- pom.xml 引用：`<dependency><groupId>org.apache.commons</groupId><artifactId>commons-statistics-bom</artifactId><version>1.3</version></dependency>`
