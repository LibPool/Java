# apache-jena-osgi

> 标签: Java, Java 8+

## 简介

Apache Jena OSGi distribution and test

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- https://central.sonatype.com/artifact/org.apache.jena%3Aapache-jena-osgi

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/jena/apache-jena-osgi/
- Maven 坐标：`org.apache.jena:apache-jena-osgi`
- pom.xml 引用：`<dependency><groupId>org.apache.jena</groupId><artifactId>apache-jena-osgi</artifactId><version>4.1.0</version></dependency>`
