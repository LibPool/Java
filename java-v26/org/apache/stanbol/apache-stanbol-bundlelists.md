# apache-stanbol-bundlelists

> 标签: Java, Java 8+

## 简介

Pseudo project to build all Stanbol OSGi bundlelists

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- 1.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/stanbol/apache-stanbol-bundlelists/
- Maven 坐标：`org.apache.stanbol:apache-stanbol-bundlelists`
- pom.xml 引用：`<dependency><groupId>org.apache.stanbol</groupId><artifactId>apache-stanbol-bundlelists</artifactId><version>1.0.0</version></dependency>`
