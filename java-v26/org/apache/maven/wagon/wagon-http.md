# wagon-http

> 标签: 构建工具, Java 8+

## 简介

Wagon provider that gets and puts artifacts through HTTP(S) using Apache HttpClient-4.x.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
