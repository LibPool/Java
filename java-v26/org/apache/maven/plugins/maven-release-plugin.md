# maven-release-plugin

> 标签: 发布, 构建插件, Java 8+

## 简介

This plugin is used to release a project with Maven, saving a lot of repetitive, manual work.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
