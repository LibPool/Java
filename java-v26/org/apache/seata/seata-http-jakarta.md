# seata-http-jakarta

> 标签: Java, Java 8+

## 简介

http-jakarta integration for Seata built with Maven

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://seata.apache.org

## 历史版本号

- 2.1.0
- 2.2.0
- 2.3.0
- 2.4.0
- 2.5.0
- 2.6.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/seata/seata-http-jakarta/
- Maven 坐标：`org.apache.seata:seata-http-jakarta`
- pom.xml 引用：`<dependency><groupId>org.apache.seata</groupId><artifactId>seata-http-jakarta</artifactId><version>2.6.0</version></dependency>`
