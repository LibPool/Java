# log4j-jakarta-web

> 标签: Java, Java 11+

## 简介

The Apache Log4j support for Jakarta EE 9+ web servlet containers

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/logging/log4j/log4j-jakarta-web/
- Maven 坐标：`org.apache.logging.log4j:log4j-jakarta-web`
- pom.xml 引用：`<dependency><groupId>org.apache.logging.log4j</groupId><artifactId>log4j-jakarta-web</artifactId><version>3.0.0-alpha1</version></dependency>`
