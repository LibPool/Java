# samples

> 标签: Java, Java 8+

## 简介

Apache OpenWebBeans Samples contains samples project for openwebbeans.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.apache.openwebbeans%3Asamples

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/openwebbeans/samples/
- Maven 坐标：`org.apache.openwebbeans:samples`
- pom.xml 引用：`<dependency><groupId>org.apache.openwebbeans</groupId><artifactId>samples</artifactId><version>4.1.1</version></dependency>`
