# camel-spring-boot-upgrade-recipes

> 标签: Java, Java 8+

## 简介

Migration recipes (using openrewrite) for Camel Spring Boot to make Maven migrations easier

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
