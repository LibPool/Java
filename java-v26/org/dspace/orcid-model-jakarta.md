# orcid-model-jakarta

> 标签: github, Java 17+

## 简介

Forked version of ORCID Model API to support Jakarta EE

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/DSpace/orcid-model

## 历史版本号

- 3.3.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/dspace/orcid-model-jakarta/
- Maven 坐标：`org.dspace:orcid-model-jakarta`
- pom.xml 引用：`<dependency><groupId>org.dspace</groupId><artifactId>orcid-model-jakarta</artifactId><version>3.3.0</version></dependency>`
