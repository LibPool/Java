# dropwizard-jakarta-xml-ws-parent

> 标签: github, Java 8+

## 简介

A Dropwizard Bundle that enables building SOAP web services and client using Jakarta XML Web Services in Dropwizard applications.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
