# devefx-spring-boot

> 标签: github, Java 8+

## 简介

Spring Boot Support for Devefx

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/devefx/spring-boot-starters

## 历史版本号

- 0.0.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/devefx/spring/boot/devefx-spring-boot/
- Maven 坐标：`org.devefx.spring.boot:devefx-spring-boot`
- pom.xml 引用：`<dependency><groupId>org.devefx.spring.boot</groupId><artifactId>devefx-spring-boot</artifactId><version>0.0.1</version></dependency>`
