# kaleido-spring

> 标签: Java, Java 8+

## 简介

Spring integration for the injection of kaleido components

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.kaleidofoundry%3Akaleido-spring

## 历史版本号

- 0.9.0
- 0.10.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/kaleidofoundry/kaleido-spring/
- Maven 坐标：`org.kaleidofoundry:kaleido-spring`
- pom.xml 引用：`<dependency><groupId>org.kaleidofoundry</groupId><artifactId>kaleido-spring</artifactId><version>0.10.1</version></dependency>`
