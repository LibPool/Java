# spring-security-otp

> 标签: Java, Java 8+

## 简介

Spring Security one-time password.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://oxerr.org/spring-security-otp

## 历史版本号

- 1.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/oxerr/spring/security/spring-security-otp/
- Maven 坐标：`org.oxerr.spring.security:spring-security-otp`
- pom.xml 引用：`<dependency><groupId>org.oxerr.spring.security</groupId><artifactId>spring-security-otp</artifactId><version>1.0.0</version></dependency>`
- 源码仓库：https://github.com/sutra/spring-security-otp/tree/master
