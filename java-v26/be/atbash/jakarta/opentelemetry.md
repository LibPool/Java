# opentelemetry

> 标签: Java, Java 11+

## 简介

Atbash Jakarta OpenTelemetry implementation

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/be.atbash.jakarta%3Aopentelemetry

## 历史版本号

- 0.9.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/be/atbash/jakarta/opentelemetry/
- Maven 坐标：`be.atbash.jakarta:opentelemetry`
