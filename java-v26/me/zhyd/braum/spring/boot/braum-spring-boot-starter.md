# braum-spring-boot-starter

> 标签: Java, Java 8+

## 简介

Spring Boot Support for Braum

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://gitee.com/yadong.zhang/braum-spring-boot-starter

## 历史版本号

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/me/zhyd/braum/spring/boot/braum-spring-boot-starter/
