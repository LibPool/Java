# spring-boot-starter-data-ultipa

> 标签: Java, Java 8+

## 简介

Starter for using Spring Data Ultipa

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://ultipa.com/projects/spring-boot-ultipa

## 历史版本号

- 1.0.0-alpha

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/tangwangwang/spring-boot-starter-data-ultipa/
- Maven 坐标：`com.tangwangwang:spring-boot-starter-data-ultipa`
- pom.xml 引用：`<dependency><groupId>com.tangwangwang</groupId><artifactId>spring-boot-starter-data-ultipa</artifactId><version>1.0.0-alpha</version></dependency>`
