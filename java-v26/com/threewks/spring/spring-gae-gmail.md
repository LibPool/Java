# spring-gae-gmail

> 标签: github, Java 8+

## 简介

Spring Boot, Google App Engine and Gmail integration

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/3wks/spring-gae-gmail

## 历史版本号

- 1.0.0-beta-2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/threewks/spring/spring-gae-gmail/
- Maven 坐标：`com.threewks.spring:spring-gae-gmail`
- pom.xml 引用：`<dependency><groupId>com.threewks.spring</groupId><artifactId>spring-gae-gmail</artifactId><version>1.0.0-beta-2</version></dependency>`
- 源码仓库：https://github.com/3wks/spring-gae-gmail.git
