# spring-mybatis-starter

> 标签: Java, Java 8+

## 简介

Spring boot starter for mybatis

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/com.touscm%3Aspring-mybatis-starter

## 历史版本号

- 1.2.7
- 1.2.8
- 1.2.9
- 1.3.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/touscm/spring-mybatis-starter/
- Maven 坐标：`com.touscm:spring-mybatis-starter`
- pom.xml 引用：`<dependency><groupId>com.touscm</groupId><artifactId>spring-mybatis-starter</artifactId><version>1.3.0</version></dependency>`
