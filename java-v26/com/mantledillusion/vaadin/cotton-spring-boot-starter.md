# cotton-spring-boot-starter

> 标签: Java, Java 8+

## 简介

Cotton module for Spring Boot based Vaadin applications.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
