# spring-ams

> 标签: github, Java 17+

## 简介

Client Library for integrating Spring applications with SAP Authorization Management Service (AMS)

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/sap/cloud/security/ams/client/spring-ams/
- Maven 坐标：`com.sap.cloud.security.ams.client:spring-ams`
- pom.xml 引用：`<dependency><groupId>com.sap.cloud.security.ams.client</groupId><artifactId>spring-ams</artifactId><version>3.8.1</version></dependency>`
