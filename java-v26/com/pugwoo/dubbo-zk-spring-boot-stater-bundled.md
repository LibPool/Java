# dubbo-zk-spring-boot-stater-bundled

> 标签: github, Java 8+

## 简介

pom dependencies for dubbo and zookeeper in spring boot

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/pugwoo/dubbo-zk-spring-boot-starter-bundled

## 历史版本号

- 2.7.0
- 2.7.1
- 2.7.4.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/pugwoo/dubbo-zk-spring-boot-stater-bundled/
- Maven 坐标：`com.pugwoo:dubbo-zk-spring-boot-stater-bundled`
- pom.xml 引用：`<dependency><groupId>com.pugwoo</groupId><artifactId>dubbo-zk-spring-boot-stater-bundled</artifactId><version>2.7.4.1</version></dependency>`
