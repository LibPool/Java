# vaadin-spring-boot-starter

> 标签: Java, Java 8+

## 简介

Spring Boot Starter for Vaadin Flow applications.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/vaadin/vaadin-spring-boot-starter/

- pom.xml 引用：`<dependency><groupId>com.vaadin</groupId><artifactId>vaadin-spring-boot-starter</artifactId><version>25.3.0</version></dependency>`
