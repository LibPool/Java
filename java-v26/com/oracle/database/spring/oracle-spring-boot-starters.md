# oracle-spring-boot-starters

> 标签: github, Java 17+

## 简介

Global parent pom.xml to be used by Oracle Spring Boot Starters modules.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/oracle/database/spring/oracle-spring-boot-starters/
- Maven 坐标：`com.oracle.database.spring:oracle-spring-boot-starters`
- pom.xml 引用：`<dependency><groupId>com.oracle.database.spring</groupId><artifactId>oracle-spring-boot-starters</artifactId><version>26.3.0</version></dependency>`
- 源码仓库：https://github.com/oracle/spring-cloud-oracle
