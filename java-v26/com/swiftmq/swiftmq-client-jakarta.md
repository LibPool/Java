# swiftmq-client-jakarta

> 标签: github, Java 11+

## 简介

Client for SwiftMQ Messaging System with Jakarta JMS 1.1 and AMQP 1.0.

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
