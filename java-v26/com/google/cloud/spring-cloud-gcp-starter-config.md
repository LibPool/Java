# spring-cloud-gcp-starter-config

> 标签: github, Java 8+

## 简介

Starter for Spring Cloud Config Client using Google Runtime Configuration API

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
