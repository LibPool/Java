# google-cloud-storage

> 标签: GCP, github, 云存储, Java 8+

## 简介

Java idiomatic client for Google Cloud Storage.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- https://github.com/googleapis/google-cloud-java

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/google/cloud/google-cloud-storage/
- Maven 坐标：`com.google.cloud:google-cloud-storage`
- pom.xml 引用：`<dependency><groupId>com.google.cloud</groupId><artifactId>google-cloud-storage</artifactId><version>2.73.0</version></dependency>`
