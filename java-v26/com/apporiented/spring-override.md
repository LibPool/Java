# spring-override

> 标签: github, Java 8+

## 简介

Namespace handler that allows for overriding, extending or modifying Spring beans in an modular environment.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/lbehnke/spring-override

## 历史版本号

- 1.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/apporiented/spring-override/
- Maven 坐标：`com.apporiented:spring-override`
