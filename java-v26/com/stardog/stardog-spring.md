# stardog-spring

> 标签: github, Java 8+

## 简介

Stardog Spring bindings for using Stardog with the Springframework

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/stardog/stardog-spring/
- Maven 坐标：`com.stardog:stardog-spring`
- pom.xml 引用：`<dependency><groupId>com.stardog</groupId><artifactId>stardog-spring</artifactId><version>7.2.1</version></dependency>`
