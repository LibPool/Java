# elasticsearch-spring-boot

> 标签: github, Java 8+

## 简介

基于 elasticsearch 高版本API做的一款扩展工具包

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/battcn/elasticsearch-spring-boot-starter.git

## 历史版本号

- 1.0.1.RELEASE

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/battcn/elasticsearch-spring-boot/
- Maven 坐标：`com.battcn:elasticsearch-spring-boot`
- pom.xml 引用：`<dependency><groupId>com.battcn</groupId><artifactId>elasticsearch-spring-boot</artifactId><version>1.0.1.RELEASE</version></dependency>`
- 源码仓库：http://blog.battcn.com
