# spring-boot-framework

> 标签: Java, Java 8+

## 简介

Development framework for spring boot applications running on AWS. Utilities for development configuration profiles for localstack use. Autoconfiguration for request log tracing and distributed visibility. Use at your own risk.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
