# dsbridge-spring

> 标签: Java, Java 8+

## 简介

A bridge for getting sql data source by spring container.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://repo1.maven.org/maven2/

## 历史版本号

- 1.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/samlic/dsbridge-spring/
- Maven 坐标：`com.samlic:dsbridge-spring`
- pom.xml 引用：`<dependency><groupId>com.samlic</groupId><artifactId>dsbridge-spring</artifactId><version>1.0.0</version></dependency>`
- 源码仓库：https://gitee.com/gogogoyon/dsbridge-spring
