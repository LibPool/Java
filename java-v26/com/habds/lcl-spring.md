# lcl-spring

> 标签: github, Java 8+

## 简介

Extension classes simplifying integration of lcl-core with Spring Framework

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
