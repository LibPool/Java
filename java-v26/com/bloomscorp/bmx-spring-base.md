# bmx-spring-base

> 标签: github, Java 8+

## 简介

Base package with managed dependencies for Spring Boot applications. This is an opinionated version of Spring Boot configuration with added as-is dependency configurations.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
