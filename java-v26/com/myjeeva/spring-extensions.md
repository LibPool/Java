# spring-extensions

> 标签: Java, Java 8+

## 简介

Spring Extensions for spring-framework

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://www.myjeeva.com/spring-extensions

## 历史版本号

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/myjeeva/spring-extensions/
- Maven 坐标：`com.myjeeva:spring-extensions`
- pom.xml 引用：`<dependency><groupId>com.myjeeva</groupId><artifactId>spring-extensions</artifactId><version>1.0.1</version></dependency>`
