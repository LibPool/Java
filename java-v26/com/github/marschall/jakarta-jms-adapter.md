# jakarta-jms-adapter

> 标签: github, Java 17+

## 简介

Adapts a javax.jms JMS provider to a jakarta.jms JMS provider.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
