# spring-auto-mock

> 标签: github, Java 8+

## 简介

Automocks the dependencies in Spring your test magically

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/rinoto/spring-auto-mock

## 历史版本号

- 0.3

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/github/rinoto/spring/spring-auto-mock/
- Maven 坐标：`com.github.rinoto.spring:spring-auto-mock`
- pom.xml 引用：`<dependency><groupId>com.github.rinoto.spring</groupId><artifactId>spring-auto-mock</artifactId><version>0.3</version></dependency>`
