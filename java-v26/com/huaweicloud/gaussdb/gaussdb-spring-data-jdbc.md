# gaussdb-spring-data-jdbc

> 标签: Java, Java 17+

## 简介

Spring Data module for JDBC repositories.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 官网

- https://projects.spring.io/spring-data-jdbc

## 历史版本号

- 3.4.0
- 3.5.0.RC1
- 3.5.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/huaweicloud/gaussdb/gaussdb-spring-data-jdbc/
- Maven 坐标：`com.huaweicloud.gaussdb:gaussdb-spring-data-jdbc`
- pom.xml 引用：`<dependency><groupId>com.huaweicloud.gaussdb</groupId><artifactId>gaussdb-spring-data-jdbc</artifactId><version>3.5.0</version></dependency>`
