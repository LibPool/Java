# embedmongo-spring

> 标签: github, Java 8+

## 简介

A builder and Spring FactoryBean for EmbedMongo

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
