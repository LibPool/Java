# spring-security-lti13

> 标签: github, Java 8+

## 简介

A LTI 1.3 implementation for Spring Security that builds on the OAuth2 support

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
