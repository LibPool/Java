# spring-mvc-archetype

> 标签: Java, Java 8+

## 简介

An extremely simple Spring MVC archetype, configured with NO XML.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://ntier.co

## 历史版本号

- 1.0.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/co/ntier/spring-mvc-archetype/
- Maven 坐标：`co.ntier:spring-mvc-archetype`
- pom.xml 引用：`<dependency><groupId>co.ntier</groupId><artifactId>spring-mvc-archetype</artifactId><version>1.0.2</version></dependency>`
