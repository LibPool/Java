# judo-spring-boot-starter

> 标签: github, Java 8+

## 简介

JUDO Stater project to support JSL-based Spring Boot application development

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/BlackBeltTechnology/judo-jsl-springboot-starter

## 历史版本号

- 1.0.3

- Maven 仓库地址：https://repo.maven.apache.org/maven2/hu/blackbelt/judo/judo-spring-boot-starter/
