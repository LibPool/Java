# jakarta.el-api

> 标签: Java, Java 11+

## 简介

Jakarta Expression Language defines an expression language for Java applications

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/jakarta/el/jakarta.el-api/
- Maven 坐标：`jakarta.el:jakarta.el-api`
- pom.xml 引用：`<dependency><groupId>jakarta.el</groupId><artifactId>jakarta.el-api</artifactId><version>6.1.0-M2</version></dependency>`
- 源码仓库：https://github.com/jakartaee/expression-language
