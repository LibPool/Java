# rest-tck-suite

> 标签: Java, Java 17+

## 简介

This module contains a Junit 5 Suite and Extension to limit the tests from the RESTful TCK

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
