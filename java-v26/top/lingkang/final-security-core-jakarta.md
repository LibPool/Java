# final-security-core-jakarta

> 标签: Java, Java 8+

## 简介

final-security，一个基于RBAC，专注于授权认证的轻量级框架

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
