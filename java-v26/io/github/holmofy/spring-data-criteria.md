# spring-data-criteria

> 标签: github, Java 17+

## 简介

Spring Data Criteria extends Spring Data JDBC &amp; Spring Data R2DBC to support dynamic sql.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
