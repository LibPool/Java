# tiles-request-jakarta-servlet

> 标签: Java, Java 8+

## 简介

Tiles request implementation for Jakarta-Servlet technology.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://weblegacy.github.io/tiles-request-jakarta-servlet/

## 历史版本号

- 1.0.0
