# camel-spring-ldap

> 标签: Java, Java 8+

## 简介

The spring-ldap component allows you to perform searches in LDAP servers using filters as the message payload.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
