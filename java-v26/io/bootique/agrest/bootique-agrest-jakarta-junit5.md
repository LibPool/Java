# bootique-agrest-jakarta-junit5

> 标签: Java, Java 11+

## 简介

Provides common JUnit5-based helper classes for test Agrest requests

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
