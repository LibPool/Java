# bootique-shiro-web-jakarta

> 标签: Java, Java 11+

## 简介

Provides Apache Shiro integration with Bootique in servlet environment (Jakarta flavor).

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
