## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/spring/platform/platform-versions/
- Maven 坐标：`io.spring.platform:platform-versions`
- pom.xml 引用：`<dependency><groupId>io.spring.platform</groupId><artifactId>platform-versions</artifactId><version>1.1.5.RELEASE</version></dependency>`
- 源码仓库：https://github.com/spring-io/platform
