# spring-boot-starter-flow

> 标签: github, Java 8+

## 简介

Spring Boot Starter for Vaadin Flow (only) applications. Also brings in Viritin add-on for better Flow DX.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/viritin/viritin-sb

## 历史版本号

- 1.0.0
- 1.0.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/in/virit/spring-boot-starter-flow/
- Maven 坐标：`in.virit:spring-boot-starter-flow`
- pom.xml 引用：`<dependency><groupId>in.virit</groupId><artifactId>spring-boot-starter-flow</artifactId><version>1.0.1</version></dependency>`
