# mongodb-spring

> 标签: Java, Java 8+

## 简介

Common Library of ipokerface

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://gitee.com/PokerFace_Fo/IPoker-Java

## 历史版本号

- 2.1.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/cn/ipokerface/mongodb-spring/
- Maven 坐标：`cn.ipokerface:mongodb-spring`

- 源码仓库：https://gitee.com/PokerFace_Fo/IPoker-Java
