# jackson-datatype-jakarta-mail

> 标签: github, Java 17+

## 简介

Add-on module for Jackson (http://github.com/FasterXML/jackson) to support working with Jakarta Mail types

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 官网

- http://github.com/FasterXML/jackson-datatypes-misc

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/tools/jackson/datatype/jackson-datatype-jakarta-mail/
- Maven 坐标：`tools.jackson.datatype:jackson-datatype-jakarta-mail`
- pom.xml 引用：`<dependency><groupId>tools.jackson.datatype</groupId><artifactId>jackson-datatype-jakarta-mail</artifactId><version>3.2.3</version></dependency>`
