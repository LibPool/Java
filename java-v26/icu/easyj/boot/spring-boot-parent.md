# spring-boot-parent

> 标签: Java, Java 8+

## 简介

为了在spring-boot项目中，更方便的使用EasyJ的功能， 此项目提供了EasyJ每个功能的starter，方便快速引用功能所需的依赖同时提供了自动装配类。 同时，一些仅spring-boot项目才能用的功能，都在此仓库中开发和维护。

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
