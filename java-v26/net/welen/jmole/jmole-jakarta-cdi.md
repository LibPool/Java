# jmole-jakarta-cdi

> 标签: Java, Java 8+

## 简介

JMole CDI starter

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/net/welen/jmole/jmole-jakarta-cdi/
- Maven 坐标：`net.welen.jmole:jmole-jakarta-cdi`
- pom.xml 引用：`<dependency><groupId>net.welen.jmole</groupId><artifactId>jmole-jakarta-cdi</artifactId><version>2.0.6</version></dependency>`
