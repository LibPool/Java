# jakarta-lemon-archetype

> 标签: Java, Java 8+

## 简介

This archetype is the basis for creating projects based on Jakarta EE using the Jakarta Lemon plugin.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
