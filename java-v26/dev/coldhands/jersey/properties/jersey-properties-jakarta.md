# jersey-properties-jakarta

> 标签: Java, Java 11+

## 简介

Includes a hk2 injection resolver and jakarta feature for integration with your Jersey application.

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/dev.coldhands.jersey.properties%3Ajersey-properties-jakarta

## 历史版本号

- 1.0.0
