# sigtest-maven-plugin

> 标签: github, Java 11+

## 简介

Signature test to compare APIs of two versions of JARs of the same library.

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
