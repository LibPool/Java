# jedis

> 标签: NoSQL, Redis, github, Java 8+

## 简介

Jedis is a blazingly small and sane Redis java client.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/redis/clients/jedis/
- Maven 坐标：`redis.clients:jedis`
- pom.xml 引用：`<dependency><groupId>redis.clients</groupId><artifactId>jedis</artifactId><version>8.1.0-beta1</version></dependency>`
