# ka-spring-base

> 标签: Java, Java 8+

## 简介

Ka-Spring base project, which builds all modules.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 历史版本号

- 0.9

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/kasource/ka-spring-base/
- Maven 坐标：`org.kasource:ka-spring-base`
- pom.xml 引用：`<dependency><groupId>org.kasource</groupId><artifactId>ka-spring-base</artifactId><version>0.9</version></dependency>`
