# spring-security-oauth-parent

> 标签: Java, Java 8+

## 简介

Parent Project for OAuth Support for Spring Security

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://oauth.googlecode.com/svn/code/maven/

## 历史版本号

- 3.17.SS3
- 3.18.SS3
- 3.19.SS3

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/codehaus/spring-security-oauth/spring-security-oauth-parent/
- Maven 坐标：`org.codehaus.spring-security-oauth:spring-security-oauth-parent`
- pom.xml 引用：`<dependency><groupId>org.codehaus.spring-security-oauth</groupId><artifactId>spring-security-oauth-parent</artifactId><version>3.19.SS3</version></dependency>`
