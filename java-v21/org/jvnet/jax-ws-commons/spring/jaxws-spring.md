# jaxws-spring

> 标签: Java, Java 8+

## 简介

Configure JAX-WS with Spring

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- java-net:/jax-ws-commons/trunk/www/spring/

## 历史版本号

- 1.9

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/jvnet/jax-ws-commons/spring/jaxws-spring/
- Maven 坐标：`org.jvnet.jax-ws-commons.spring:jaxws-spring`
- pom.xml 引用：`<dependency><groupId>org.jvnet.jax-ws-commons.spring</groupId><artifactId>jaxws-spring</artifactId><version>1.9</version></dependency>`
