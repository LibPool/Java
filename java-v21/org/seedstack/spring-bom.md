# spring-bom

> 标签: Java, Java 8+

## 简介

spring-bom - Java library from Maven Central

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.seedstack%3Aspring-bom

## 历史版本号

- 2.0.0-M2
- 2.0.0-M3
- 2.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/seedstack/spring-bom/
- Maven 坐标：`org.seedstack:spring-bom`
- pom.xml 引用：`<dependency><groupId>org.seedstack</groupId><artifactId>spring-bom</artifactId><version>2.0.0</version></dependency>`
