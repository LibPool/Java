# annotations

> 标签: github, 注解, 空安全, Java 8+

## 简介

A set of annotations used for code inspection support and code documentation.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
