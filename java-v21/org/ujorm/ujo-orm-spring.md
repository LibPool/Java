# ujo-orm-spring

> 标签: Java, Java 8+

## 简介

Quick ORM implementation based on the UJO objects.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://ujorm.org

## 历史版本号

- 1.30.RC1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/ujorm/ujo-orm-spring/
- Maven 坐标：`org.ujorm:ujo-orm-spring`
- pom.xml 引用：`<dependency><groupId>org.ujorm</groupId><artifactId>ujo-orm-spring</artifactId><version>1.30.RC1</version></dependency>`
- 源码仓库：http://ujoframework.svn.sourceforge.net/viewvc/ujoframework/trunk/project-m2/ujo-spring/
