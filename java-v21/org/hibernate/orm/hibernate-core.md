# hibernate-core

> 标签: ORM, 数据库, Java 17+

## 简介

Hibernate's core ORM functionality

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/hibernate/orm/hibernate-core/
- Maven 坐标：`org.hibernate.orm:hibernate-core`
- pom.xml 引用：`<dependency><groupId>org.hibernate.orm</groupId><artifactId>hibernate-core</artifactId><version>8.0.0.Beta1</version></dependency>`
- 源码仓库：https://github.com/hibernate/hibernate-orm
