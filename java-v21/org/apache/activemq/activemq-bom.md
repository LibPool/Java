# activemq-bom

> 标签: Java, Java 8+

## 简介

ActiveMQ BOM (Bill of Materials)

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/activemq/activemq-bom/
- Maven 坐标：`org.apache.activemq:activemq-bom`
- pom.xml 引用：`<dependency><groupId>org.apache.activemq</groupId><artifactId>activemq-bom</artifactId><version>6.3.2</version></dependency>`
- 源码仓库：https://github.com/apache/activemq/activemq-bom
