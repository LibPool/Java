# bom

> 标签: Java, Java 8+

## 简介

Apache OpenWebBeans BOM parent, mainly to simplify jakarta stack consumption.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.apache.openwebbeans.bom%3Abom

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/openwebbeans/bom/bom/
- Maven 坐标：`org.apache.openwebbeans.bom:bom`
- pom.xml 引用：`<dependency><groupId>org.apache.openwebbeans.bom</groupId><artifactId>bom</artifactId><version>4.1.1</version></dependency>`
