# pekko-management-bom_2.13

> 标签: Java, Java 8+

## 简介

Apache Pekko Management is a suite of tools for operating Apache Pekko Clusters. (depending on Scala 2.13)

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
