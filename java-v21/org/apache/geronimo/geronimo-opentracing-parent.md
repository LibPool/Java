# geronimo-opentracing-parent

> 标签: Java, Java 8+

## 简介

Apache Geronimo implementation of the Microprofile OpenTracing Specification

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://gitbox.apache.org/repos/asf/geronimo-opentracing.git

## 历史版本号

- 1.0.1
- 1.0.2
- 1.0.3

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/geronimo/geronimo-opentracing-parent/
- Maven 坐标：`org.apache.geronimo:geronimo-opentracing-parent`
- pom.xml 引用：`<dependency><groupId>org.apache.geronimo</groupId><artifactId>geronimo-opentracing-parent</artifactId><version>1.0.3</version></dependency>`
- 源码仓库：https://gitbox.apache.org/repos/asf/geronimo-opentracing.git
