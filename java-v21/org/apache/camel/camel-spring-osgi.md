# camel-spring-osgi

> 标签: Java, Java 8+

## 简介

Camel Spring support with OSGi

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.apache.camel%3Acamel-spring-osgi

## 历史版本号

- 2.1.0
- 2.2.0
- 2.3.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/camel/camel-spring-osgi/
- Maven 坐标：`org.apache.camel:camel-spring-osgi`
- pom.xml 引用：`<dependency><groupId>org.apache.camel</groupId><artifactId>camel-spring-osgi</artifactId><version>2.3.0</version></dependency>`
