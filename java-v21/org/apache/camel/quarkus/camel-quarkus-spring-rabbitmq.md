# camel-quarkus-spring-rabbitmq

> 标签: Java, Java 17+

## 简介

Send and receive messages from RabbitMQ using the Spring RabbitMQ client.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
