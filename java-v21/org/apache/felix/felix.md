# felix

> 标签: Java, Java 8+

## 简介

Apache felix is an OSGi implementation.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://felix.apache.org/

## 历史版本号

- 1.0.0
- 1.0.1
- 1.0.2
- 1.0.3
- 1.0.4

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/felix/felix/
- Maven 坐标：`org.apache.felix:felix`
- pom.xml 引用：`<dependency><groupId>org.apache.felix</groupId><artifactId>felix</artifactId><version>1.0.4</version></dependency>`
