# distribution

> 标签: Java, Java 8+

## 简介

distribution - Java library from Maven Central

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.apache.rocketmq%3Adistribution

## 历史版本号

- 1.0.0
- 1.0.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/rocketmq/distribution/
- Maven 坐标：`org.apache.rocketmq:distribution`
- pom.xml 引用：`<dependency><groupId>org.apache.rocketmq</groupId><artifactId>distribution</artifactId><version>1.0.1</version></dependency>`
