# common-java-spring-jpa

> 标签: Java, Java 8+

## 简介

JoinedWorkz facility for generating Spring Data JPA entities and repositories.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
