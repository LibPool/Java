# openjdk-orb-jakarta

> 标签: Java, Java 8+

## 简介

JBoss repackaging of the OpenJDK ORB (Jakarta Namespace)

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.jboss.openjdk-orb%3Aopenjdk-orb-jakarta

## 历史版本号

- 8.1.8.Final
- 8.1.9.Final

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/jboss/openjdk-orb/openjdk-orb-jakarta/
- Maven 坐标：`org.jboss.openjdk-orb:openjdk-orb-jakarta`
- pom.xml 引用：`<dependency><groupId>org.jboss.openjdk-orb</groupId><artifactId>openjdk-orb-jakarta</artifactId><version>8.1.9.Final</version></dependency>`
