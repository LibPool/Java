# mybatis-spring-boot

> 标签: Java, Java 17+

## 简介

Spring Boot Support for MyBatis

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/mybatis/spring/boot/mybatis-spring-boot/
- Maven 坐标：`org.mybatis.spring.boot:mybatis-spring-boot`
- pom.xml 引用：`<dependency><groupId>org.mybatis.spring.boot</groupId><artifactId>mybatis-spring-boot</artifactId><version>4.1.0</version></dependency>`
- 源码仓库：https://github.com/mybatis/spring-boot-starter/
