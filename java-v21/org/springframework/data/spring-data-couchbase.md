# spring-data-couchbase

> 标签: github, Java 17+

## 简介

Spring Data integration for Couchbase

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

- pom.xml 引用：`<dependency><groupId>org.springframework.data</groupId><artifactId>spring-data-couchbase</artifactId><version>6.2.0-M1</version></dependency>`
