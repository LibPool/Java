# mongodb-driver-core

> 标签: MongoDB, NoSQL, Java 8+

## 简介

Shared components for the Synchronous and Reactive Streams implementations of the MongoDB Java Driver.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
