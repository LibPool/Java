# jasypt-spring4

> 标签: Java, Java 8+

## 简介

Java library which enables encryption in java apps with minimum effort.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://www.jasypt.org

## 历史版本号

- 1.9.3

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/jasypt/jasypt-spring4/
- Maven 坐标：`org.jasypt:jasypt-spring4`
- pom.xml 引用：`<dependency><groupId>org.jasypt</groupId><artifactId>jasypt-spring4</artifactId><version>1.9.3</version></dependency>`
