# camunda8-spring-boot-adapter

> 标签: github, Java 21+

## 简介

This is an adapter which implements the binding of the VanillaBP SPI in order to run business processes using Camunda 8.

最低 Java 版本：Java 21；已收录于 java-v21, java-v25, java-v26。
