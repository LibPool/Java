# wro4spring

> 标签: github, Java 8+

## 简介

Configuration aid to use wro4j with spring

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://github.com/sevensource/wro4spring

## 历史版本号

- 0.0.1
- 0.0.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/sevensource/wro4spring/
- Maven 坐标：`org.sevensource:wro4spring`
- pom.xml 引用：`<dependency><groupId>org.sevensource</groupId><artifactId>wro4spring</artifactId><version>0.0.2</version></dependency>`
- 源码仓库：http://github.com/sevensource/wro4spring
