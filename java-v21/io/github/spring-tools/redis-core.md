# redis-core

> 标签: Java, Java 8+

## 简介

Redis Tools 的核心包，包括一些 spring-data-redis 引用

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/io.github.spring-tools%3Aredis-core

## 历史版本号

- 1.0.0
- 1.1.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/github/spring-tools/redis-core/
- Maven 坐标：`io.github.spring-tools:redis-core`
- pom.xml 引用：`<dependency><groupId>io.github.spring-tools</groupId><artifactId>redis-core</artifactId><version>1.1.0</version></dependency>`
