# querydsl-apt-for-records

> 标签: github, Java 11+

## 简介

APT based Source code generation for Querydsl, modified to support Java records

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/mingeun0507/querydsl

## 历史版本号

- 5.0.0.M1
- 5.0.1

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/github/mingeun0507/querydsl-apt-for-records/
