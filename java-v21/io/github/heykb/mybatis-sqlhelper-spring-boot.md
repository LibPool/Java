# mybatis-sqlHelper-spring-boot

> 标签: Java, Java 8+

## 简介

MyBatis 多租户、逻辑删除、数据权限插件-SqlHelper Spring Boot版本

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
