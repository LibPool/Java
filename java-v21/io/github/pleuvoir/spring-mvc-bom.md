spring-mvc-bom - Java library from Maven Central

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/io.github.pleuvoir%3Aspring-mvc-bom

- 1.1.0
