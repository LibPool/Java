# common-ext-jakarta

> 标签: github, Java 17+

## 简介

this is a common extensions written in kotlin, work for jvm(17+). it almost has nothing depends in runtime, user should declare it by themself.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
