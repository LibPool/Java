# spring-nats

> 标签: Java, Java 8+

## 简介

NATS Implementation for Spring

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://www.nats.io

## 历史版本号

- 0.3.0
- 0.3.1
- 0.3.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/nats/spring-nats/
- Maven 坐标：`io.nats:spring-nats`
- pom.xml 引用：`<dependency><groupId>io.nats</groupId><artifactId>spring-nats</artifactId><version>0.3.2</version></dependency>`
