# common

> 标签: github, Java 8+

## 简介

Logisfera Nova Commons holds a bunch of useful helpers such as validators, conditional register process, soap logging handler

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网
