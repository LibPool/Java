# spring-zeebe-connector-runtime

> 标签: Java, Java 11+

## 简介

Camunda Connector - Self-contained runtime that can connect to any Zeebe/Operate instance

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
