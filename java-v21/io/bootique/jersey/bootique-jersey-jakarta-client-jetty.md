# bootique-jersey-jakarta-client-jetty

> 标签: Java, Java 11+

## 简介

Sets Jetty HttpClient as the default transport for Jersey client

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/io.bootique.jersey%3Abootique-jersey-jakarta-client-jetty

## 历史版本号

- 3.0.M2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/bootique/jersey/bootique-jersey-jakarta-client-jetty/
- Maven 坐标：`io.bootique.jersey:bootique-jersey-jakarta-client-jetty`
- pom.xml 引用：`<dependency><groupId>io.bootique.jersey</groupId><artifactId>bootique-jersey-jakarta-client-jetty</artifactId><version>3.0.M2</version></dependency>`
