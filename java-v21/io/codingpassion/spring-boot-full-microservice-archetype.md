# spring-boot-full-microservice-archetype

> 标签: github, Java 8+

## 简介

Maven Archetype which can be used to generate Spring Boot microservice application with additional configuration and tools.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/PiotrRaszkowski/spring-boot-full-microservice-archetype

## 历史版本号

- 0.1
- 0.1.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/codingpassion/spring-boot-full-microservice-archetype/
- Maven 坐标：`io.codingpassion:spring-boot-full-microservice-archetype`
- pom.xml 引用：`<dependency><groupId>io.codingpassion</groupId><artifactId>spring-boot-full-microservice-archetype</artifactId><version>0.1.1</version></dependency>`
