# spring

> 标签: Java, Java 8+

## 简介

Mongock module for Spring related runners

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/mongock/spring/
- Maven 坐标：`io.mongock:spring`
- pom.xml 引用：`<dependency><groupId>io.mongock</groupId><artifactId>spring</artifactId><version>5.5.1</version></dependency>`
