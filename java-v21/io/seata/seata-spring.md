# seata-spring

> 标签: Java, Java 8+

## 简介

spring for Seata built with Maven

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/seata/seata-spring/
- Maven 坐标：`io.seata:seata-spring`
- pom.xml 引用：`<dependency><groupId>io.seata</groupId><artifactId>seata-spring</artifactId><version>2.0.0</version></dependency>`
