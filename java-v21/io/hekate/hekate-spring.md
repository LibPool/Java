# hekate-spring

> 标签: github, Java 8+

## 简介

Java library for cluster communications and computing.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/hekate/hekate-spring/
- Maven 坐标：`io.hekate:hekate-spring`
- pom.xml 引用：`<dependency><groupId>io.hekate</groupId><artifactId>hekate-spring</artifactId><version>4.1.3</version></dependency>`
- 源码仓库：https://github.com/hekate-io/hekate
