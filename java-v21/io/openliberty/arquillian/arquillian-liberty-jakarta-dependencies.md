# arquillian-liberty-jakarta-dependencies

> 标签: github, Java 8+

## 简介

Jakarta Liberty dependency bundles for the Arquillian Project

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- pom.xml 引用：`<dependency><groupId>io.openliberty.arquillian</groupId><artifactId>arquillian-liberty-jakarta-dependencies</artifactId><version>3.0.0</version></dependency>`
