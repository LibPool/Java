# activemq-client-jakarta

> 标签: Java, Java 8+

## 简介

ActiveMQ Client Jakarta

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://activemq.apache.org

## 历史版本号

- 5.18.0.hyte-1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/hyte/activemq/activemq-client-jakarta/
- Maven 坐标：`io.hyte.activemq:activemq-client-jakarta`
- pom.xml 引用：`<dependency><groupId>io.hyte.activemq</groupId><artifactId>activemq-client-jakarta</artifactId><version>5.18.0.hyte-1</version></dependency>`
- 源码仓库：https://github.com/hyteio/activemq-client-jakarta
