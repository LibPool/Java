# kalix-spring-boot-parent

> 标签: Java, Java 21+

## 简介

This is the parent pom for Kalix applications based on Spring. It contains all dependencies and plugins to build a Kalix service using the Kalix Java SDK.

最低 Java 版本：Java 21；已收录于 java-v21, java-v25, java-v26。
