# jetty-spring

> 标签: Java, Java 8+

## 简介

jetty-spring - Java library from Maven Central

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/jetty%3Ajetty-spring

## 历史版本号

- 6.0.0rc3
- 6.0.0
- 6.0.0rc4

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/jetty/jetty-spring/
- Maven 坐标：`jetty:jetty-spring`
- pom.xml 引用：`<dependency><groupId>jetty</groupId><artifactId>jetty-spring</artifactId><version>6.0.0rc4</version></dependency>`
