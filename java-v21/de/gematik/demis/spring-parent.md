# spring-parent

> 标签: github, Java 21+

## 简介

This project serves as a parent POM for other demis spring boot based projects. It provides common dependency management and build plugin configurations for child projects.

最低 Java 版本：Java 21；已收录于 java-v21, java-v25, java-v26。
