# spring-remoting-amqp

> 标签: github, Java 8+

## 简介

A library to use Spring-Remoting via the AMQP protocol.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/davidbilge/Spring-Remoting-AMQP

## 历史版本号

- 1.0.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/de/davidbilge/spring/spring-remoting-amqp/
- Maven 坐标：`de.davidbilge.spring:spring-remoting-amqp`
- pom.xml 引用：`<dependency><groupId>de.davidbilge.spring</groupId><artifactId>spring-remoting-amqp</artifactId><version>1.0.2</version></dependency>`
- 源码仓库：https://github.com/davidbilge/Spring-Remoting-AMQP
