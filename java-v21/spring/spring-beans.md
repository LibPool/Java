# spring-beans

> 标签: Java, Java 8+

## 简介

spring-beans - Java library from Maven Central

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/spring%3Aspring-beans

## 历史版本号

- 1.0.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/spring/spring-beans/
- Maven 坐标：`spring:spring-beans`
- pom.xml 引用：`<dependency><groupId>spring</groupId><artifactId>spring-beans</artifactId><version>1.0.2</version></dependency>`
