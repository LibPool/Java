# commons-orm-spring-boot-starter

> 标签: Java, Java 8+

## 简介

project commons 适用所有java项目的公共库, 方便快速集成和使用, 提供工作效率

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://gitee.com/sgy_project/project-commons/commons-orm-spring-boot-starter

- 1.0.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/cn/fscode/commons/commons-orm-spring-boot-starter/
- Maven 坐标：`cn.fscode.commons:commons-orm-spring-boot-starter`
- pom.xml 引用：`<dependency><groupId>cn.fscode.commons</groupId><artifactId>commons-orm-spring-boot-starter</artifactId><version>1.0.1</version></dependency>`
- 源码仓库：https://gitee.com/sgy_project/project-commons
