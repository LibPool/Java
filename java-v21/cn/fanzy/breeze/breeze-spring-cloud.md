# breeze-spring-cloud

> 标签: Java, Java 8+

## 简介

A set of highly available components for SpringBoot 2.x.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
