# nav-jakarta

> 标签: Java, Java 21+

## 简介

API to elegantly navigate JSON structures and extract data. This artifact provides the adapter for Jakarta JSON Processing.

最低 Java 版本：Java 21；已收录于 java-v21, java-v25, java-v26。
