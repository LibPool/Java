# hofund-spring-boot-starter

> 标签: Java, Java 8+

## 简介

A Spring Boot starter to easily integrate Hofund functionalities into Spring Boot applications. This starter includes dependencies and configurations for quick setup, while also serving as a toolset to monitor applications, manage connections, and discover the current state of system components.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
