# spring-boot-starter-piranha-embedded

> 标签: Java, Java 17+

## 简介

This module delivers the Spring Boot starter for Piranha Embedded.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
