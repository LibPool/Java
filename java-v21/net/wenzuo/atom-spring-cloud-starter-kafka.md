> 标签: github, Java 21+

## 简介

Atom is a Spring Boot starter project, providing a set of reusable components and configurations to help developers quickly build modern, scalable, and maintainable Java applications.

最低 Java 版本：Java 21；已收录于 java-v21, java-v25, java-v26。
