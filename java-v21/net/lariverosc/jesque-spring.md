# jesque-spring

> 标签: github, Java 8+

## 简介

An extension for Jesque that allows interoperability with Spring

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/lariverosc/jesque-spring

## 历史版本号

- 1.0.0
- 1.0.1
- 1.0.3

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/net/lariverosc/jesque-spring/
- Maven 坐标：`net.lariverosc:jesque-spring`
- pom.xml 引用：`<dependency><groupId>net.lariverosc</groupId><artifactId>jesque-spring</artifactId><version>1.0.3</version></dependency>`
