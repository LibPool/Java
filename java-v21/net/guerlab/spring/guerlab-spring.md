# guerlab-spring

> 标签: Java, Java 8+

## 简介

guerlab spring extension

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/net/guerlab/spring/guerlab-spring/
- Maven 坐标：`net.guerlab.spring:guerlab-spring`
- pom.xml 引用：`<dependency><groupId>net.guerlab.spring</groupId><artifactId>guerlab-spring</artifactId><version>5.1.4</version></dependency>`
- 源码仓库：https://gitee.com/guerlab_net/guerlab-spring
