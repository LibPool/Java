# spring-request-aware

> 标签: Java, Java 8+

## 简介

Allows injection of the in-flight ServletRequest in a Spring web application.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
