# spring-full

> 标签: Java, Java 8+

## 简介

spring-full - Java library from Maven Central

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/springframework%3Aspring-full

## 历史版本号

- 1.0.1
- 1.1-rc1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/springframework/spring-full/
- Maven 坐标：`springframework:spring-full`
- pom.xml 引用：`<dependency><groupId>springframework</groupId><artifactId>spring-full</artifactId><version>1.1-rc1</version></dependency>`
