# guice-servlet

> 标签: github, Java 8+

## 简介

Google guice repackaged for jakartaee

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/xvik/guice-jakartaee

## 历史版本号

- 5.1.0-rc.1
- 5.1.0-rc.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/ru/vyarus/guice/jakarta/guice-servlet/
- Maven 坐标：`ru.vyarus.guice.jakarta:guice-servlet`
- pom.xml 引用：`<dependency><groupId>ru.vyarus.guice.jakarta</groupId><artifactId>guice-servlet</artifactId><version>5.1.0-rc.2</version></dependency>`
- 源码仓库：https://github.com/xvik/guice-jakartaee
