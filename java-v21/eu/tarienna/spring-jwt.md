# spring-jwt

> 标签: github, Java 8+

## 简介

JWT integration for Spring web projects with Spring security.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/tarienna/spring-jwt

## 历史版本号

- 0.1.0
- 0.2.0
- 1.0.0

- Maven 仓库地址：https://repo.maven.apache.org/maven2/eu/tarienna/spring-jwt/
