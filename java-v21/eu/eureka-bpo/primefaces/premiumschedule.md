# premiumschedule

> 标签: github, Java 8+

## 简介

Eureka-BPO PremiumSchedule - Schedule Component for Primefaces with premium FullCalendar features: Vertical Resource View and Timeline View

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/eureka-bpo/primefaces-premiumschedule

## 历史版本号

- 13.0.0

- Maven 仓库地址：https://repo.maven.apache.org/maven2/eu/eureka-bpo/primefaces/premiumschedule/
