# filesystem-spring-boot

> 标签: github, Java 8+

## 简介

A springboot starter for filesystem utils, or use client via manually property object without springboot.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/IceLitty/filesystem-spring-boot

## 历史版本号

- 1.0
- 1.1
- 1.2
- 1.3

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/moe/icyr/filesystem-spring-boot/
- Maven 坐标：`moe.icyr:filesystem-spring-boot`
- pom.xml 引用：`<dependency><groupId>moe.icyr</groupId><artifactId>filesystem-spring-boot</artifactId><version>1.3</version></dependency>`
- 源码仓库：https://github.com/IceLitty/filesystem-spring-boot
