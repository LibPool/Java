# commons-transaction-spring

> 标签: github, Java 8+

## 简介

A PlatformTransactionManager implementation and a few Spring Extensions for using Commons Transaction from Apache for transactional file access.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
