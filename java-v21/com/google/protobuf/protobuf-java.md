# protobuf-java

> 标签: RPC, 序列化, Java 8+

## 简介

Core Protocol Buffers library. Protocol Buffers are a way of encoding structured data in an efficient yet extensible format.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
