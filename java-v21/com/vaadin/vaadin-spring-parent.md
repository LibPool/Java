# vaadin-spring-parent

> 标签: github, Java 8+

## 简介

Parent module for Spring integration for Vaadin applications.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/vaadin/vaadin-spring-parent/

- pom.xml 引用：`<dependency><groupId>com.vaadin</groupId><artifactId>vaadin-spring-parent</artifactId><version>19.1.3</version></dependency>`
