# vaadin-spring

> 标签: Java, Java 21+

## 简介

Provides Spring integration for Vaadin applications.

最低 Java 版本：Java 21；已收录于 java-v21, java-v25, java-v26。

- pom.xml 引用：`<dependency><groupId>com.vaadin</groupId><artifactId>vaadin-spring</artifactId><version>25.3.0</version></dependency>`
