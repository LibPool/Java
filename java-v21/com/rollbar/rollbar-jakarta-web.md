# rollbar-jakarta-web

> 标签: github, Java 11+

## 简介

For connecting your applications built on the JVM to Rollbar for Error Reporting

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/rollbar/rollbar-java

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/rollbar/rollbar-jakarta-web/
- Maven 坐标：`com.rollbar:rollbar-jakarta-web`
- pom.xml 引用：`<dependency><groupId>com.rollbar</groupId><artifactId>rollbar-jakarta-web</artifactId><version>2.3.1</version></dependency>`
- 源码仓库：https://github.com/rollbar/rollbar-java
