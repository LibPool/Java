# spring-batch-support-pom

> 标签: github, Java 8+

## 简介

Namics Spring Batch Support Library aims to provide some sugar to use spring-batch.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/namics/spring-batch-support

- 1.1.1
