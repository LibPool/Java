# nils4spring-parent

> 标签: github, Java 17+

## 简介

Parent POM of the NILS integration into the Spring Framework

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/codepulsar-com/nils4spring

## 历史版本号

- 1.1.0

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/codepulsar/nils/nils4spring-parent/
- Maven 坐标：`com.codepulsar.nils:nils4spring-parent`

- 源码仓库：https://github.com/codepulsar-com/nils4spring
