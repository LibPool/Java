# cor-bean-processor-spring-boot-starter

> 标签: github, Java 17+

## 简介

A Spring Boot starter to help creating the chain of responsibility (COR) bean processor.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
