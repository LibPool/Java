# cds-starter-spring-boot-odata

> 标签: Java, Java 8+

## 简介

Starter package to write Spring Boot based CAP applications with OData V4 service exposure

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
