# lswagger-spring

> 标签: Java, Java 8+

## 简介

依赖Springfox框架,生成Spring的增强文档

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/com.lichongbing%3Alswagger-spring

## 历史版本号

- 3.0.3
- 3.0.4
- 3.0.5

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/lichongbing/lswagger-spring/
- Maven 坐标：`com.lichongbing:lswagger-spring`
- pom.xml 引用：`<dependency><groupId>com.lichongbing</groupId><artifactId>lswagger-spring</artifactId><version>3.0.5</version></dependency>`
