# spring-boot-starter-scala

> 标签: Java, Java 8+

## 简介

A spring-boot starter for scala language.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://repo.artima.com/releases

## 历史版本号

- 2.3.4-0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/infilos/spring-boot-starter-scala/
- Maven 坐标：`com.infilos:spring-boot-starter-scala`
- pom.xml 引用：`<dependency><groupId>com.infilos</groupId><artifactId>spring-boot-starter-scala</artifactId><version>2.3.4-0</version></dependency>`
- 源码仓库：https://github.com/infilos/spring-boot-starter-scala/tree/master
