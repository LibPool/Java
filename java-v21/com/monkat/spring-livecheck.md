# spring-livecheck

> 标签: github, Java 8+

## 简介

A simple spring based health check library for live systems that cannot easily create and rely on using test or dummy data to verify the health of a system.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/monkat/spring-livecheck/

- pom.xml 引用：`<dependency><groupId>com.monkat</groupId><artifactId>spring-livecheck</artifactId><version>0.0.7</version></dependency>`
