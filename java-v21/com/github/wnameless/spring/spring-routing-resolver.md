# spring-routing-resolver

> 标签: github, Java 8+

## 简介

An easy way to find out all routing paths in Spring annotated controllers

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
