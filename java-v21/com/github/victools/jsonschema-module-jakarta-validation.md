# jsonschema-module-jakarta-validation

> 标签: Java, Java 17+

## 简介

Module for the jsonschema-generator – deriving JSON Schema attributes from jakarta.validation annotations

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
