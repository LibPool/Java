# ddphin-spring-boot

> 标签: github, Java 8+

## 简介

Collect the complex data and sync to elasticsearch intrusivly and automaticly.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
