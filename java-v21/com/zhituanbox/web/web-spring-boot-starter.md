# web-spring-boot-starter

> 标签: Java, Java 8+

## 简介

spring web 常用配置：异常链接，Response包装，跨域

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://gitee.com/liuyangbox/web-spring-boot-starter

## 历史版本号

- 1.0.0
- 1.1.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/zhituanbox/web/web-spring-boot-starter/
- Maven 坐标：`com.zhituanbox.web:web-spring-boot-starter`
