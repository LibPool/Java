# jackson-datatype-jakarta-jsonp

> 标签: github, Java 8+

## 简介

Add-on module for Jackson (https://github.com/FasterXML/jackson) to support working with JSON-P (JSON Processing) node types (new Jakarta flavor) via data-binding

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
