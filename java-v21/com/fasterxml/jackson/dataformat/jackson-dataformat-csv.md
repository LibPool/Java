# jackson-dataformat-csv

> 标签: CSV, github, 序列化, Java 8+

## 简介

Support for reading and writing CSV-encoded data via Jackson abstractions.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
