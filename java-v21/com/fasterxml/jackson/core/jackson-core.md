# jackson-core

> 标签: JSON, github, 流式解析, Java 8+

## 简介

Core Jackson processing abstractions (aka Streaming API), implementation for JSON

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
