# jackson-jakarta-rs-smile-provider

> 标签: Java, Java 8+

## 简介

Functionality to handle Smile (binary JSON) input/output for Jakarta-RS implementations (like Jersey and RESTeasy) using standard Jackson data binding.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
