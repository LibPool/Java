# fastjson

> 标签: JSON, github, 序列化, Java 8+

## 简介

Fastjson is a JSON processor (JSON parser + JSON generator) written in Java

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
