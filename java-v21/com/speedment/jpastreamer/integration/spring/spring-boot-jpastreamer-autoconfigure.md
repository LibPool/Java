# spring-boot-jpastreamer-autoconfigure

> 标签: Java, Java 11+

## 简介

A Spring Boot AutoConfiguration module that adds support for JPAStreamer autowiring.

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
