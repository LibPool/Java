# azure-spring-boot-bom

> 标签: github, Java 8+

## 简介

BOM for Microsoft Azure Spring Boot Support

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/azure/spring/azure-spring-boot-bom/
- Maven 坐标：`com.azure.spring:azure-spring-boot-bom`
- pom.xml 引用：`<dependency><groupId>com.azure.spring</groupId><artifactId>azure-spring-boot-bom</artifactId><version>4.0.0</version></dependency>`
- 源码仓库：https://github.com/Azure/azure-sdk-for-java
