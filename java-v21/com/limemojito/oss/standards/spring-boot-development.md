# spring-boot-development

> 标签: Java, Java 8+

## 简介

Builds a standard boot container. Need to supply source layout and set packaging to jar.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
