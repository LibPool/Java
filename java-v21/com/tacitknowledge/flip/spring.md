# spring

> 标签: Java, Java 8+

## 简介

Flip extensions for working with Spring Framework

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/com.tacitknowledge.flip%3Aspring

## 历史版本号

- 1.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/tacitknowledge/flip/spring/
- Maven 坐标：`com.tacitknowledge.flip:spring`
- pom.xml 引用：`<dependency><groupId>com.tacitknowledge.flip</groupId><artifactId>spring</artifactId><version>1.0</version></dependency>`
