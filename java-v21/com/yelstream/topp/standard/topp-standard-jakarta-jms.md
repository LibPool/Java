# topp-standard-jakarta-jms

> 标签: github, Java 21+

## 简介

Topp Standard Jakarta JMS Library addressing basics of Jakarta JMS.

最低 Java 版本：Java 21；已收录于 java-v21, java-v25, java-v26。
