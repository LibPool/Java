# spring-dependencies-autoconfigure

> 标签: github, Java 8+

## 简介

Spring auto configuration for the dependencies-maven-plugin

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/fegbers/spring-dependencies-autoconfigure

## 历史版本号

- 0.1.0-RC

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/de/fegbers/spring/spring-dependencies-autoconfigure/
- Maven 坐标：`de.fegbers.spring:spring-dependencies-autoconfigure`
- pom.xml 引用：`<dependency><groupId>de.fegbers.spring</groupId><artifactId>spring-dependencies-autoconfigure</artifactId><version>0.1.0-RC</version></dependency>`
- 源码仓库：https://github.com/fegbers/spring-dependencies-autoconfigure.git
