# mvn-spring-boot-swing-parent

> 标签: Java, Java 8+

## 简介

Parent project for general swing projects that uses spring-boot

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://www.alpharogroup.de/

## 历史版本号

- 2.1.2
- 2.1.3
- 2.1.4

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/de/alpharogroup/mvn-spring-boot-swing-parent/
- Maven 坐标：`de.alpharogroup:mvn-spring-boot-swing-parent`
- pom.xml 引用：`<dependency><groupId>de.alpharogroup</groupId><artifactId>mvn-spring-boot-swing-parent</artifactId><version>2.1.4</version></dependency>`
