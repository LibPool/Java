# mail-extensions-spring-boot

> 标签: github, Java 8+

## 简介

Parent for Spring Boot Starters that autoconfigures advanced Spring Mail senders

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/V1ncNet/mail-extensions-spring-boot.git

## 历史版本号

- 2.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/de/vinado/boot/mail-extensions-spring-boot/
- Maven 坐标：`de.vinado.boot:mail-extensions-spring-boot`
- pom.xml 引用：`<dependency><groupId>de.vinado.boot</groupId><artifactId>mail-extensions-spring-boot</artifactId><version>2.0.0</version></dependency>`
- 源码仓库：https://github.com/V1ncNet/mail-extensions-spring-boot
