# spring

> 标签: Java, Java 8+

## 简介

Library contains some useful classes for Rest API

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://gitlab.com/vui-la/api/spring

## 历史版本号

- 1.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/la/vui/api/spring/
- Maven 坐标：`la.vui.api:spring`
- pom.xml 引用：`<dependency><groupId>la.vui.api</groupId><artifactId>spring</artifactId><version>1.0.0</version></dependency>`
- 源码仓库：https://gitlab.com/vui.la/api/spring.git
