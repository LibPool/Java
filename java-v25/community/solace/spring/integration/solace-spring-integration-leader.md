# solace-spring-integration-leader

> 标签: github, Java 17+

## 简介

This project allows for Spring Integration Leader Election using Solace Exclusive Queues

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
