# easy-spring-service

> 标签: Java, Java 8+

## 简介

Easy Spring Service

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://www.easyspring.io/

## 历史版本号

- 1.1.0-RELEASE

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/easyspring/service/easy-spring-service/
- Maven 坐标：`io.easyspring.service:easy-spring-service`
- pom.xml 引用：`<dependency><groupId>io.easyspring.service</groupId><artifactId>easy-spring-service</artifactId><version>1.1.0-RELEASE</version></dependency>`
