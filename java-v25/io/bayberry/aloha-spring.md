# aloha-spring

> 标签: github, Java 8+

## 简介

An aloha extension module to provide easy integration with spring boot

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/pojozhang/aloha

## 历史版本号

- 1.0.2-alpha
- 1.0.4-alpha

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/bayberry/aloha-spring/
- Maven 坐标：`io.bayberry:aloha-spring`
- pom.xml 引用：`<dependency><groupId>io.bayberry</groupId><artifactId>aloha-spring</artifactId><version>1.0.4-alpha</version></dependency>`
- 源码仓库：https://github.com/pojozhang/aloha
