# kjson-spring3

> 标签: github, Java 17+

## 简介

Message converter which simplifies use of kjson by Spring Boot 3 applications

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/kjson/kjson-spring3/

- pom.xml 引用：`<dependency><groupId>io.kjson</groupId><artifactId>kjson-spring3</artifactId><version>9.9</version></dependency>`
