# kjson-spring

> 标签: github, Java 8+

## 简介

Message converter which simplifies use of kjson by Spring applications

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/kjson/kjson-spring/
- Maven 坐标：`io.kjson:kjson-spring`
- pom.xml 引用：`<dependency><groupId>io.kjson</groupId><artifactId>kjson-spring</artifactId><version>7.1</version></dependency>`
- 源码仓库：https://github.com/pwall567/kjson-spring.git
