# hami-spring-boot-starter

> 标签: github, Java 8+

## 简介

Out-of-box framework for SpringBoot

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/dovemy/hami

## 历史版本号

- 1.0.0
- 1.0.1
- 1.0.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/github/dovemy/hami-spring-boot-starter/
- Maven 坐标：`io.github.dovemy:hami-spring-boot-starter`
- pom.xml 引用：`<dependency><groupId>io.github.dovemy</groupId><artifactId>hami-spring-boot-starter</artifactId><version>1.0.2</version></dependency>`
