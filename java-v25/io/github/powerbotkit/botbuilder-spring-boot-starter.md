# botbuilder-spring-boot-starter

> 标签: github, Java 8+

## 简介

a simple starter for spring boot and bot framework

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/PowerBotKit/botbuilder-spring-boot

## 历史版本号

- 0.0.1
- 0.0.2
- 0.0.3

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/github/powerbotkit/botbuilder-spring-boot-starter/
- Maven 坐标：`io.github.powerbotkit:botbuilder-spring-boot-starter`
- pom.xml 引用：`<dependency><groupId>io.github.powerbotkit</groupId><artifactId>botbuilder-spring-boot-starter</artifactId><version>0.0.3</version></dependency>`
