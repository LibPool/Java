# spring-kafka-streams-dist

> 标签: github, Java 11+

## 简介

Spring Kafka Streams is a Spring Boot library that brings new features to improve the implementation of Kafka Streams.

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
