# spring-boot-starter-dependencies

> 标签: github, Java 17+

## 简介

all useful dependencies management for spring boot starter

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/yao-wenbin/spring-boot-starter-dependencies

## 历史版本号

- 1.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/github/yao-wenbin/spring-boot-starter-dependencies/
- Maven 坐标：`io.github.yao-wenbin:spring-boot-starter-dependencies`
- pom.xml 引用：`<dependency><groupId>io.github.yao-wenbin</groupId><artifactId>spring-boot-starter-dependencies</artifactId><version>1.0</version></dependency>`
