# dc-spring-boot-starter-jpa

> 标签: github, Java 21+

## 简介

jpa扩展，基于querydsl保障类型安全（字段等信息修改遗漏可在编译期提示错误，避免修改遗漏导致错误出现在运行时），支持复杂的增删改查，简化自定义通用查询片段的注入方式（可实现任意复杂的高级查询）

最低 Java 版本：Java 21；已收录于 java-v21, java-v25, java-v26。
