# dc-spring-boot-starter-cache

> 标签: github, Java 21+

## 简介

扩展spring缓存，更友好的配置方式，支持redis缓存、caffeine本地缓存（支持多节点同步）

最低 Java 版本：Java 21；已收录于 java-v21, java-v25, java-v26。
