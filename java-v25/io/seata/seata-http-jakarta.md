# seata-http-jakarta

> 标签: Java, Java 8+

## 简介

http-client integration for Seata built with Maven

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://seata.io

- 1.7.1
- 1.8.0
- 2.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/io/seata/seata-http-jakarta/
- Maven 坐标：`io.seata:seata-http-jakarta`
- pom.xml 引用：`<dependency><groupId>io.seata</groupId><artifactId>seata-http-jakarta</artifactId><version>2.0.0</version></dependency>`
