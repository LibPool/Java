# jakarta-lemon-plugin

> 标签: Java, Java 11+

## 简介

This plugin allows you to create Jakarta EE applications following the standard guidelines.

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
