# fastball-spring

## 简介

fastball-spring - Java library from Maven Central

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/dev.fastball%3Afastball-spring

- Maven 仓库地址：https://repo.maven.apache.org/maven2/dev/fastball/fastball-spring/
- Maven 坐标：`dev.fastball:fastball-spring`
- pom.xml 引用：`<dependency><groupId>dev.fastball</groupId><artifactId>fastball-spring</artifactId><version>0.1.0</version></dependency>`
