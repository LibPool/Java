# jakarta-data-parent

> 标签: Java, Java 11+

## 简介

Create the specification in Jakarta EE to help Jakarta EE developers create enterprise-grade applications applying Java® and data engine technologies. It helps them create scalable applications while maintaining low coupling with the underlying persistence technology.

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
