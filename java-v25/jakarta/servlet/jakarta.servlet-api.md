# jakarta.servlet-api

> 标签: Servlet规范, Web, Java 17+

## 简介

Jakarta Servlet defines a server-side API for handling HTTP requests and responses

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
