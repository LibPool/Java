# sigtest-maven-plugin

> 标签: github, Java 8+

## 简介

Signature test to compare APIs of two versions of JARs of the same library.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/eclipse-ee4j/jakartaee-tck-tools/wiki

## 历史版本号

- 2.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/jakarta/tck/tools/sigtest-maven-plugin/
- Maven 坐标：`jakarta.tck.tools:sigtest-maven-plugin`
- pom.xml 引用：`<dependency><groupId>jakarta.tck.tools</groupId><artifactId>sigtest-maven-plugin</artifactId><version>2.0</version></dependency>`
- 源码仓库：https://github.com/eclipse-ee4j/jakartaee-tck-tools/tools/sigtest
