# core-tck-jsonp-extension

> 标签: Java, Java 17+

## 简介

This is an experimental feature that allows a container to run the JSON-P unit tests from within the container using Arquillian. This is not required for EE10.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
