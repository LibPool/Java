# panda-spring-boot-starter

> 标签: Java, Java 8+

## 简介

the package contains all package poms for spring boot, without needing to import other necessary packages

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/com.justtoplay.panda%3Apanda-spring-boot-starter

## 历史版本号

- 1.0.1
- 1.0.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/justtoplay/panda/panda-spring-boot-starter/
- Maven 坐标：`com.justtoplay.panda:panda-spring-boot-starter`
- pom.xml 引用：`<dependency><groupId>com.justtoplay.panda</groupId><artifactId>panda-spring-boot-starter</artifactId><version>1.0.2</version></dependency>`
