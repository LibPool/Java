# javapoet

> 标签: github, 代码生成, Java 8+

## 简介

Use beautiful Java code to generate beautiful Java code.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/squareup/javapoet/
- Maven 坐标：`com.squareup:javapoet`
- pom.xml 引用：`<dependency><groupId>com.squareup</groupId><artifactId>javapoet</artifactId><version>1.13.0</version></dependency>`
- 源码仓库：http://github.com/square/javapoet/
