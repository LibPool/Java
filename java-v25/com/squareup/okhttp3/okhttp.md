# okhttp

> 标签: HTTP客户端, Java 8+

## 简介

Square’s meticulous HTTP client for Java and Kotlin.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/squareup/okhttp3/okhttp/
- Maven 坐标：`com.squareup.okhttp3:okhttp`
- pom.xml 引用：`<dependency><groupId>com.squareup.okhttp3</groupId><artifactId>okhttp</artifactId><version>5.5.0</version></dependency>`
- 源码仓库：https://github.com/lysine-dev/okhttp
