# spring-repository-template

> 标签: github, Java 8+

## 简介

Reusable repository template

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/Wilddiary/workflow-tests.git

## 历史版本号

- 1.0.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/wilddiary/spring-repository-template/
- Maven 坐标：`com.wilddiary:spring-repository-template`
- pom.xml 引用：`<dependency><groupId>com.wilddiary</groupId><artifactId>spring-repository-template</artifactId><version>1.0.1</version></dependency>`
