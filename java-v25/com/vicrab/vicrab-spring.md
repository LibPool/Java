# vicrab-spring

> 标签: Java, Java 8+

## 简介

Spring exception handler and servlet initializer for sending exceptions to Vicrab.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://maven.apache.org

## 历史版本号

- 1.1
- 1.2
- 1.2.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/vicrab/vicrab-spring/
- Maven 坐标：`com.vicrab:vicrab-spring`
- pom.xml 引用：`<dependency><groupId>com.vicrab</groupId><artifactId>vicrab-spring</artifactId><version>1.2.1</version></dependency>`
