# db2-spring-boot-starter

> 标签: Java, Java 8+

## 简介

db2-spring-boot-starter. You can use this jar for autoconfiguration of JCC properties for Db2 LUW server.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/ibm/db2/jcc/db2-spring-boot-starter/

- pom.xml 引用：`<dependency><groupId>com.ibm.db2.jcc</groupId><artifactId>db2-spring-boot-starter</artifactId><version>0.0.1</version></dependency>`
