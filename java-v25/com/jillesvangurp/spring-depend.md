# spring-depend

> 标签: github, Java 8+

## 简介

A tool for generating a spring bean dependency graph

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/jillesvangurp/spring-depend

## 历史版本号

- 0.1
- 0.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/jillesvangurp/spring-depend/
- Maven 坐标：`com.jillesvangurp:spring-depend`
- pom.xml 引用：`<dependency><groupId>com.jillesvangurp</groupId><artifactId>spring-depend</artifactId><version>0.2</version></dependency>`
