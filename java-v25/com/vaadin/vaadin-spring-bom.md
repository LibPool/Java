## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/vaadin/vaadin-spring-bom/
- Maven 坐标：`com.vaadin:vaadin-spring-bom`
- pom.xml 引用：`<dependency><groupId>com.vaadin</groupId><artifactId>vaadin-spring-bom</artifactId><version>25.3.0</version></dependency>`
