# spring-test-dbunit-core

> 标签: github, Java 8+

## 简介

Core module for the integration between the Spring testing framework and DBUnit

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/sporniket/spring-test-dbunit

## 历史版本号

- 5.2.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/sporniket/spring-test-dbunit/spring-test-dbunit-core/
- Maven 坐标：`com.sporniket.spring-test-dbunit:spring-test-dbunit-core`
- pom.xml 引用：`<dependency><groupId>com.sporniket.spring-test-dbunit</groupId><artifactId>spring-test-dbunit-core</artifactId><version>5.2.1</version></dependency>`
