## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/emc/documentum/spring/spring-data-documentum/

- pom.xml 引用：`<dependency><groupId>com.emc.documentum.spring</groupId><artifactId>spring-data-documentum</artifactId><version>0.0.1</version></dependency>`
