# spring-tx

> 标签: github, Java 8+

## 简介

Spring Transaction. Patched version of org.springframework spring-tx 5.2.3.RELEASE. See issue https://github.com/spring-projects/spring-framework/issues/24291

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/spring-projects/spring-framework

- 5.2.2.RELEASE.patched
- 5.2.3.RELEASE.patched
