# gcs-analytics-core-parent

> 标签: github, Java 11+

## 简介

A Java library designed to optimize and accelerate analytics workloads on Google Cloud Storage (GCS).

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
