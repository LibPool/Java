# google-api-client

> 标签: API客户端, Java 8+

## 简介

Google APIs Client Library for Java

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/google/api-client/google-api-client/
- Maven 坐标：`com.google.api-client:google-api-client`
- pom.xml 引用：`<dependency><groupId>com.google.api-client</groupId><artifactId>google-api-client</artifactId><version>2.9.1</version></dependency>`
