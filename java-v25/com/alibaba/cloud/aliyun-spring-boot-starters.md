# aliyun-spring-boot-starters

> 标签: Java, Java 8+

## 简介

Spring Boot Starters for Aliyun Services

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/alibaba/cloud/aliyun-spring-boot-starters/
- Maven 坐标：`com.alibaba.cloud:aliyun-spring-boot-starters`
- pom.xml 引用：`<dependency><groupId>com.alibaba.cloud</groupId><artifactId>aliyun-spring-boot-starters</artifactId><version>1.0.0</version></dependency>`
