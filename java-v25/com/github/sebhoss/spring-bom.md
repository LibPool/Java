# spring-bom

> 标签: Java, Java 8+

## 简介

spring-bom - Java library from Maven Central

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- https://central.sonatype.com/artifact/com.github.sebhoss%3Aspring-bom

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/github/sebhoss/spring-bom/
- Maven 坐标：`com.github.sebhoss:spring-bom`
- pom.xml 引用：`<dependency><groupId>com.github.sebhoss</groupId><artifactId>spring-bom</artifactId><version>2.0.6</version></dependency>`
