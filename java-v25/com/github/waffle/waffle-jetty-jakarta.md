# waffle-jetty-jakarta

> 标签: Java, Java 17+

## 简介

Jetty Jakarta integration for WAFFLE

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 官网

- https://waffle.github.io/waffle/

## 历史版本号

- 3.4.0
- 3.5.0
- 3.5.1
- 3.6.0
- 3.7.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/github/waffle/waffle-jetty-jakarta/
- Maven 坐标：`com.github.waffle:waffle-jetty-jakarta`
- pom.xml 引用：`<dependency><groupId>com.github.waffle</groupId><artifactId>waffle-jetty-jakarta</artifactId><version>3.7.0</version></dependency>`
- 源码仓库：https://github.com/Waffle/waffle
