# systemd-spring-boot

> 标签: github, Java 8+

## 简介

Systemd/watchdog integration for Spring Boot

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/dpimkin/systemd-spring-boot-starter

## 历史版本号

- 0.0.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/github/dpimkin/systemd/systemd-spring-boot/
- Maven 坐标：`com.github.dpimkin.systemd:systemd-spring-boot`
- pom.xml 引用：`<dependency><groupId>com.github.dpimkin.systemd</groupId><artifactId>systemd-spring-boot</artifactId><version>0.0.1</version></dependency>`
- 源码仓库：https://github.com/dpimkin/systemd-spring-boot-starter
