# coherence-spring-project

> 标签: github, Java 8+

## 简介

The Oracle Coherence Spring Integration provides mechanism to bridge and support the use of Spring with Coherence and vice-versa.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/coherence-community/coherence-spring

## 历史版本号

- 2.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/oracle/coherence/spring/coherence-spring-project/
- Maven 坐标：`com.oracle.coherence.spring:coherence-spring-project`
- pom.xml 引用：`<dependency><groupId>com.oracle.coherence.spring</groupId><artifactId>coherence-spring-project</artifactId><version>2.0.0</version></dependency>`
- 源码仓库：https://github.com/coherence-community/coherence-spring.git
