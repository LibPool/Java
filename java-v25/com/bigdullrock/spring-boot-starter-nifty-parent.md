# spring-boot-starter-nifty-parent

> 标签: github, Java 8+

## 简介

Spring Boot Starter for the Nifty Thift Library

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/bigdullrock/spring-boot-starter-nifty

## 历史版本号

- 0.3.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/bigdullrock/spring-boot-starter-nifty-parent/
- Maven 坐标：`com.bigdullrock:spring-boot-starter-nifty-parent`
- pom.xml 引用：`<dependency><groupId>com.bigdullrock</groupId><artifactId>spring-boot-starter-nifty-parent</artifactId><version>0.3.0</version></dependency>`
