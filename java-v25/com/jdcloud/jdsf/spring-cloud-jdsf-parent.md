# spring-cloud-jdsf-parent

> 标签: github, Java 8+

## 简介

JDSF Spring Cloud SDK for spring cloud.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

- https://github.com/jdcloud-api/spring-cloud-jdsf

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/jdcloud/jdsf/spring-cloud-jdsf-parent/
- Maven 坐标：`com.jdcloud.jdsf:spring-cloud-jdsf-parent`
- pom.xml 引用：`<dependency><groupId>com.jdcloud.jdsf</groupId><artifactId>spring-cloud-jdsf-parent</artifactId><version>1.1.2-Hoxton</version></dependency>`
- 源码仓库：http://www.jdcloud.com
