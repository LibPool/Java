# jackson-datatype-hibernate5-jakarta

> 标签: github, Java 8+

## 简介

Add-on module for Jackson (https://github.com/FasterXML/jackson) to support Hibernate (https://hibernate.org) version 5.5 with Jakarta data types.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
