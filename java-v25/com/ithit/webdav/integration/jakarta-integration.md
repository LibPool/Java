# jakarta-integration

> 标签: Java, Java 17+

## 简介

IT Hit WebDAV integration for new Jakarta Java servlet containers

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/ithit/webdav/integration/jakarta-integration/
