# spring

> 标签: github, Java 21+

## 简介

A Kotlin library to consume and produce SQS messages

最低 Java 版本：Java 21；已收录于 java-v21, java-v25, java-v26。

## 官网

- https://github.com/katanox/tabour

## 历史版本号

- 1.0-RC

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/katanox/spring/
- Maven 坐标：`com.katanox:spring`
- pom.xml 引用：`<dependency><groupId>com.katanox</groupId><artifactId>spring</artifactId><version>1.0-RC</version></dependency>`
- 源码仓库：https://github.com/katanox/tabour
