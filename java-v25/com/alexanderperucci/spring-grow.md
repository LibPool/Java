# spring-grow

> 标签: github, Java 8+

## 简介

Maven Archetype which can generate a secured Spring MVC Web Application (XML Configuration)

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/alexander-perucci/spring-grow

## 历史版本号

- 1.0.0
- 1.0.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/com/alexanderperucci/spring-grow/
- Maven 坐标：`com.alexanderperucci:spring-grow`
- pom.xml 引用：`<dependency><groupId>com.alexanderperucci</groupId><artifactId>spring-grow</artifactId><version>1.0.1</version></dependency>`
