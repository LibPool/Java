# spring-mvc-cache-control

> 标签: github, Java 17+

## 简介

Provides an annotation @CacheControl which can be used to set the Cache-Control header in a Spring MVC controller.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
