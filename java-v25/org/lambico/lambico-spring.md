# lambico-spring

> 标签: Java, Java 8+

## 简介

Lambico implementation based on the Spring framework.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://www.lambico.org

## 历史版本号

- 1.0-beta-05
- 1.0-beta-06

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/lambico/lambico-spring/
- Maven 坐标：`org.lambico:lambico-spring`
- pom.xml 引用：`<dependency><groupId>org.lambico</groupId><artifactId>lambico-spring</artifactId><version>1.0-beta-06</version></dependency>`
