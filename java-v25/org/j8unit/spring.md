# spring

> 标签: Java, Java 8+

## 简介

The Spring extension of J8Unit.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.j8unit%3Aspring

## 历史版本号

- 4.1.7

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/j8unit/spring/
- Maven 坐标：`org.j8unit:spring`
- pom.xml 引用：`<dependency><groupId>org.j8unit</groupId><artifactId>spring</artifactId><version>4.1.7</version></dependency>`
