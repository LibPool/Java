# spring-boot-parent

## 简介

Parent for all spring-boot projects

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/ajaxer-org/spring-boot

## 历史版本号
