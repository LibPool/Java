# spring-aaa

> 标签: Java, Java 8+

## 简介

Enable Spring Application Developer to use OSGL-AAA library to implement Authentication, Authorization and Accounting

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://osgl.org/aaa/spring

## 历史版本号

- 0.1
- 1.0.0
- 1.0.1

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/osgl/spring-aaa/
- Maven 坐标：`org.osgl:spring-aaa`
- pom.xml 引用：`<dependency><groupId>org.osgl</groupId><artifactId>spring-aaa</artifactId><version>1.0.1</version></dependency>`
- 源码仓库：https://github.com/greenlaw110/spring-aaa
