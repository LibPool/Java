# jakarta.persistence

> 标签: github, Java 11+

## 简介

The Jakarta Persistence API (JPA) : a standard interface-based Java model abstraction of persistence, continuing from the JPA API.

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
