# datanucleus-jakarta-query

> 标签: github, Java 11+

## 简介

Plugin for DataNucleus providing annotation processing for Jakarta Persistence queries

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/datanucleus/${project.artifactId}

## 历史版本号

- 6.0.0-m1
- 6.0.0-release
