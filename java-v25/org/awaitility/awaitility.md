# awaitility

> 标签: 异步, 测试, Java 8+

## 简介

A Java DSL for synchronizing asynchronous operations

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
