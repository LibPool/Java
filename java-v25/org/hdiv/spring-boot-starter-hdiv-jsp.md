# spring-boot-starter-hdiv-jsp

> 标签: Java, Java 8+

## 简介

HDIV starter for Spring Boot projects that use JSP as view technology

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://www.hdiv.org

- 1.1.0
- 1.2.0
- 1.3.0
- 1.3.1
- 1.3.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/hdiv/spring-boot-starter-hdiv-jsp/
- Maven 坐标：`org.hdiv:spring-boot-starter-hdiv-jsp`
- pom.xml 引用：`<dependency><groupId>org.hdiv</groupId><artifactId>spring-boot-starter-hdiv-jsp</artifactId><version>1.3.2</version></dependency>`
