# mybatis-spring

> 标签: ORM, Spring集成, Java 17+

## 简介

An easy-to-use Spring bridge for MyBatis sql mapping framework.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
