# faktorips-runtime-jakarta-xml

> 标签: Java, Java 21+

## 简介

Faktor-IPS Runtime Extension for XML binding with Jakarta JAXB 3 as included in Java EE 9. You need to provide the jakarta.xml.bind-api as dependency. It is marked as provided here because it is often included in application servers and any version required by Faktor-IPS might collide with them.

最低 Java 版本：Java 21；已收录于 java-v21, java-v25, java-v26。
