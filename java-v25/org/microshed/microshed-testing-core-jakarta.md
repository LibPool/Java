# microshed-testing-core-jakarta

> 标签: Java, Java 11+

## 简介

A test framework for black-box testing MicroProfile and Jakarta EE applications

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://microshed.org/microshed-testing/

## 历史版本号

- 0.9.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/microshed/microshed-testing-core-jakarta/
- Maven 坐标：`org.microshed:microshed-testing-core-jakarta`
- pom.xml 引用：`<dependency><groupId>org.microshed</groupId><artifactId>microshed-testing-core-jakarta</artifactId><version>0.9.2</version></dependency>`
- 源码仓库：https://github.com/MicroShed/microshed-testing.git
