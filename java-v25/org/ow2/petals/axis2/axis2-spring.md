# axis2-spring

> 标签: Java, Java 11+

## 简介

spring for Axis2

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://axis.apache.org/axis2/java/core/

## 历史版本号

- 2.0.0-PETALS-0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/ow2/petals/axis2/axis2-spring/
- Maven 坐标：`org.ow2.petals.axis2:axis2-spring`
- pom.xml 引用：`<dependency><groupId>org.ow2.petals.axis2</groupId><artifactId>axis2-spring</artifactId><version>2.0.0-PETALS-0</version></dependency>`
- 源码仓库：https://github.com/petalslink/axis-axis2-java-core
