# spring-rest-template-logger

> 标签: github, Java 8+

## 简介

Spring RestTemplate customizer to log HTTP traffic.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/markhobson/rest-template-logger

## 历史版本号

- 1.0.0
- 2.0.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/hobsoft/spring/spring-rest-template-logger/
- Maven 坐标：`org.hobsoft.spring:spring-rest-template-logger`
