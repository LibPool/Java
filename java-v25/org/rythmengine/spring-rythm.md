# spring-rythm

> 标签: Java, Java 8+

## 简介

Enable Spring Application Developer to use Rythm Template Engine to render views

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://rythmengine.com/spring

## 历史版本号

- 1.0
- 1.2.0
- 1.2.1
- 1.2.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/rythmengine/spring-rythm/
- Maven 坐标：`org.rythmengine:spring-rythm`
- pom.xml 引用：`<dependency><groupId>org.rythmengine</groupId><artifactId>spring-rythm</artifactId><version>1.2.2</version></dependency>`
- 源码仓库：https://github.com/rythmengine/spring-rythm
