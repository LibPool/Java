# org.apache.karaf.deployer.spring

> 标签: Java, Java 11+

## 简介

This deployer transforms a plain spring xml file to a deployable bundle

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
