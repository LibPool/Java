# maven-compiler-plugin

> 标签: github, 构建插件, Java 8+

## 简介

The Compiler Plugin is used to compile the sources of your project.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
