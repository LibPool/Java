# plc4j-apache-karaf

> 标签: Java, Java 8+

## 简介

Integration module for integrating PLC4X into Apache Karaf.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://central.sonatype.com/artifact/org.apache.plc4x%3Aplc4j-apache-karaf

## 历史版本号

- 0.4.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/plc4x/plc4j-apache-karaf/
- Maven 坐标：`org.apache.plc4x:plc4j-apache-karaf`
- pom.xml 引用：`<dependency><groupId>org.apache.plc4x</groupId><artifactId>plc4j-apache-karaf</artifactId><version>0.4.0</version></dependency>`
