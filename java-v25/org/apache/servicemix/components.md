# components

> 标签: Java, Java 8+

## 简介

This pom provides the common bits for all ServiceMix components, as well as providing a reactor build for those components.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
