# apache-taverna-parent

> 标签: Java, Java 8+

## 简介

General POM-file parent for Apache Taverna projects

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://taverna.incubator.apache.org/

## 历史版本号

- 2-incubating
- 3-incubating

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/apache/taverna/apache-taverna-parent/
- Maven 坐标：`org.apache.taverna:apache-taverna-parent`
- pom.xml 引用：`<dependency><groupId>org.apache.taverna</groupId><artifactId>apache-taverna-parent</artifactId><version>3-incubating</version></dependency>`
- 源码仓库：https://github.com/apache/incubator-taverna-maven-parent/
