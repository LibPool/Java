# wicket-spring

> 标签: Java, Java 17+

## 简介

Integration project to use Spring injection in your Wicket applications. See the wicket-spring-examples for integration patterns.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
