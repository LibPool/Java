# drools-decisions-spring-boot-starter

> 标签: Java, Java 8+

## 简介

Spring Boot Starter for Drools Decisions (DMN). Contains everything you need to get started with Drools Decisions!

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
