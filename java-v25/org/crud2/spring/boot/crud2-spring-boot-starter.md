# crud2-spring-boot-starter

> 标签: github, Java 8+

## 简介

Springboot starter for crud2(A anti orm data access layer)

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/crud2/crud2-spring-boot-starter

## 历史版本号

- 0.1.0

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/crud2/spring/boot/crud2-spring-boot-starter/
- Maven 坐标：`org.crud2.spring.boot:crud2-spring-boot-starter`
- pom.xml 引用：`<dependency><groupId>org.crud2.spring.boot</groupId><artifactId>crud2-spring-boot-starter</artifactId><version>0.1.0</version></dependency>`
- 源码仓库：https://github.com/crud2/crud2-spring-boot-starter
