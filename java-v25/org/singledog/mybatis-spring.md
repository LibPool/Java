# mybatis-spring

> 标签: Java, Java 8+

## 简介

An easy-to-use Spring bridge for MyBatis sql mapping framework.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- http://www.mybatis.org/spring/

## 历史版本号

- 1.3.3

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/singledog/mybatis-spring/
- Maven 坐标：`org.singledog:mybatis-spring`
- pom.xml 引用：`<dependency><groupId>org.singledog</groupId><artifactId>mybatis-spring</artifactId><version>1.3.3</version></dependency>`
- 源码仓库：https://github.com/wupeng1988/mybatis-spring
