# spring-data-parent

> 标签: Java, Java 8+

## 简介

Global parent pom.xml to be used by Spring Data modules

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/org/springframework/data/build/spring-data-parent/
- Maven 坐标：`org.springframework.data.build:spring-data-parent`
- pom.xml 引用：`<dependency><groupId>org.springframework.data.build</groupId><artifactId>spring-data-parent</artifactId><version>4.2.0-M1</version></dependency>`
