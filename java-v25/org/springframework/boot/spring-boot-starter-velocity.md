# spring-boot-starter-velocity

> 标签: Java, Java 8+

## 简介

Starter for building MVC web applications using Velocity views. Deprecated since 1.4

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
