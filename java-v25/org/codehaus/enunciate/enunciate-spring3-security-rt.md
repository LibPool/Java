# enunciate-spring3-security-rt

> 标签: Java, Java 8+

## 简介

A pom for bundling all the (optional) dependencies needed to apply spring 3 security.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。
