# spring-resourcereader

> 标签: github, Java 8+

## 简介

Spring Component to load a Resource into a String.

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/kemitix/spring-resourcereader

## 历史版本号

- 1.0.0-RELEASE
- 1.1.1-RELEASE

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/net/kemitix/spring-resourcereader/
- Maven 坐标：`net.kemitix:spring-resourcereader`
- pom.xml 引用：`<dependency><groupId>net.kemitix</groupId><artifactId>spring-resourcereader</artifactId><version>1.1.1-RELEASE</version></dependency>`
