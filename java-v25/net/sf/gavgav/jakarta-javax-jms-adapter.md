# jakarta-javax-jms-adapter

> 标签: Java, Java 11+

## 简介

Wraps javax.jms as jakarta.jms, for example allows using Oracle AQ JMS (javax.jms) with Spring boot 3 (jakarta.jms)

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。
