# hlinfo-utils-jakarta

> 标签: github, Java 17+

## 简介

hlinfo-utils is a collection of common java tools for Jakarta EE

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/hlinfocc/hlinfo-utils-jakarta

## 历史版本号
