# spring-core

> 标签: github, Java 11+

## 简介

Bitweb Spring Boot Java Core Library

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/ee/bitweb/spring-core/
- Maven 坐标：`ee.bitweb:spring-core`
- pom.xml 引用：`<dependency><groupId>ee.bitweb</groupId><artifactId>spring-core</artifactId><version>5.1.0</version></dependency>`
- 源码仓库：https://github.com/BitWeb/java-core-lib
