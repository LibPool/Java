# jakarta-utils

> 标签: github, Java 11+

## 简介

Some helpful classes when developing Jakarta servlets

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/morgwai/servlet-utils

## 历史版本号

- 1.0

- Maven 仓库地址：https://repo.maven.apache.org/maven2/pl/morgwai/base/jakarta-utils/
