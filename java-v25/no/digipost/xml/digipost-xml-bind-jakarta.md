# digipost-xml-bind-jakarta

> 标签: github, Java 11+

## 简介

Toolset helping with some of the cumbersome XML APIs of the JDK.

最低 Java 版本：Java 11；已收录于 java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/digipost/digipost-xml/digipost-xml-bind-jakarta/

## 历史版本号

- 1.0-RC1
- 1.0-RC2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/no/digipost/xml/digipost-xml-bind-jakarta/
- Maven 坐标：`no.digipost.xml:digipost-xml-bind-jakarta`
- pom.xml 引用：`<dependency><groupId>no.digipost.xml</groupId><artifactId>digipost-xml-bind-jakarta</artifactId><version>1.0-RC2</version></dependency>`
- 源码仓库：https://github.com/digipost/digipost-xml/digipost-xml-bind-jakarta/
