# snowman-spring-boot-starter

## 简介

spring boot starter for snowman

最低 Java 版本：Java 8；已收录于 java-v8, java-v11, java-v17, java-v21, java-v25, java-v26。

## 官网

- https://github.com/chuanyichuan/snowman

- 1.0.2

## 获取地址

- Maven 仓库地址：https://repo.maven.apache.org/maven2/cc/kevinlu/snowman-spring-boot-starter/
- Maven 坐标：`cc.kevinlu:snowman-spring-boot-starter`
- pom.xml 引用：`<dependency><groupId>cc.kevinlu</groupId><artifactId>snowman-spring-boot-starter</artifactId><version>1.0.2</version></dependency>`
