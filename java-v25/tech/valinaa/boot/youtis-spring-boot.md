# youtis-spring-boot

> 标签: github, Java 17+

## 简介

Based on annotation development and perfect integration with Spring Boot 3.X. By annotating annotations on entity classes, DDL corresponding to the table structure can be automatically generated, and can also be directly executed.

最低 Java 版本：Java 17；已收录于 java-v17, java-v21, java-v25, java-v26。
